# CPU TEST support policy packs

Public API: `build_pack(root, destination, mode='reject', observe='reasons')`.
CLI: `python3 -B tools/water_sun_support_pack.py NEW.zip --mode {reject,zero} --observe {reasons,inputs}`.
All destinations are atomic no-overwrite; shipping roots/aliases, frozen reports, changed parents/certificate and malformed source seams fail closed.

The reject control preserves every frozen stable parent shader/archive member byte-for-byte and never calls the certificate. The zero candidate includes the literal approved Q24 module. Only certificate `0` skips an air-Sun node with zero angular-source contribution. Certificate `1` retains all existing stable inverse, reconstruction, reflection/receiver, kernel and legacy full/base gates. Certificate `-1` rejects through the original branch2 and whole-result full-legacy fallback. Original 48 weights are not renormalized.

`recover_helper(bytes)` and `recover_water(bytes, observe)` restore the exact same-observer frozen stable parent. Current raw physical FS is archived as `SUN-SUPPORT-physical.fsh`; it expands against the current pack helper. The old physical/helper/observer sources are independently archived as `PARENT-SUN-SUPPORT-*`. Every older provenance member remains unchanged.

Authoritative manifest: `WATER-SUN-SUPPORT.json` / `aqualumen-water-sun-support-v1`. It supersedes inherited optical/atlas policy metadata, not its provenance. No FINAL source change: inherited visual legends are explicitly not authoritative for new count semantics.

Reasons C9 remains first/grouped rejection counts; C10 is requested/applied/`certificateCounts`/rejectionCount; C11 remains covariance/production flags; C12 remains TES. The countword is `zero+64*support+4096*unknown+262144*calls`, each 0..48, with first-three sum equal calls. Calls occur once after unchanged target/axis admission, before inverse evaluation. Physical `WNS_status.z` remains unchanged. Reject counts are uncollected/zero. Pre/post-loop and target/axis exclusions can leave zero calls; they are not certified absence. Sourcekind0 is an explicit manifest constant.

Inputs C9-C12 retain mean/called, raw view/requested, covariance/flags and first failed target/encoded reason+node. Inputs C12 is **not TES**. No certificate-count interpretation is permitted for this capture; reason and inputs are separate frames. Zero branch2 combines inverse failure and certificate unknown, so its reason alone cannot distinguish them.

Evidence: two genuine public CLI RED-to-GREEN verticals, then eight public CPU contracts PASS. The fixed ordered16 coordinates and minimum4 application gate are unchanged. These are CPU packaging/source results only, not GL neutrality, runtime application, native pixel-AA equivalence, physical validity, appearance acceptance or shipping adoption. Existing R/receiver/domain exclusions, quadrature limits and unknown support remain unaccepted boundaries. Root owns all subsequent native/Iris checks.
