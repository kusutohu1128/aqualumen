# Prepared view certificate candidate: CPU only

`tools/water_sun_prepared.glsl` is a NEW standalone candidate, not a production include or built pack. It retains the exact frozen integer primitives from `shaders/lib/water_sun_support.glsl` and does not modify that file. Its public APIs are `waterSunSupportPrepareView(rawV,eta)`, `waterSunSupportClassPrepared(context,rawTarget)` and the original-shape `waterSunSupportClass(rawV,rawTarget,eta)` wrapper.

The returned context contains six exact Q24 intervals (`vx`, `vy`, `vz`, `E`, `K2`, `downScale`) and validity. `E`, `K2` and `downScale=E*(vy*vy)` retain the original expression trees. It is local to one cap invocation with identical raw view/eta bits, not reusable across arbitrary pixels or frames. The target side retains original U/B arithmetic, downward/forward tests and strict unknown/absence/support comparisons. No float repair, normalization, interval narrowing or square specialization was introduced. Preparation evaluates pure safe integer expressions even for invalid view inputs; classification still returns unknown. This changes computation scheduling, not endpoint arithmetic or output policy.

Five public CPU tests pass. Literal old and candidate GLSL are compiled through a tiny C++ type/builtin adapter, with no reimplemented classifier or mocked arithmetic. All frozen344 cases match old/prepared/wrapper class bits (29 absent,312 supported,3 unknown); all six lo/hi/valid interval triples equal the old subexpressions, including301 adjacent context reuses. A further24 invalid/boundary/overlap/overflow cases and8 signed-zero/raw-nonunit cases match. The first missing-candidate public construction RED and normal-incidence GREEN are retained. Later coverage tests were first-run GREEN; no manufactured extra RED is claimed.

No caller, loop, pack, shader resources, qualification gate, diagnostic counts, geometry or optical law was changed. Future integration must preserve axis admission, every48-node certificate invocation/counter, class−1 whole fallback and class0 source-only zero. An invalid context is not permission to short-circuit the entire loop or hide its unknown counts.

Literal source costs for a valid48-node path can decrease from912 to583 `WSP_mul` calls and336 to148 `WSP_point` calls. These are not compiled GPU instruction counts or speed results: the driver may already hoist common expressions or fold constant eta/duplicate products, and the context can raise register pressure/spills. GPU344 exact replay and actual-main generated-input/class/count/reason/C0/depth/TES identity are still required before any timing or adoption claim. Root alone decides and executes those later experiments.
