# 局所光が壁で一度反射する場合の数値基準

ランタンの周囲を5面の黒い覆いで囲み、東側だけを開ける。東の壁を赤・中立色・黒に取り替え、その壁からの光が北の白壁上の3点に届く量を積分した。環境光や空から入る光は与えていない。これは後続のゲーム実装を調べるためのCPU基準で、配布版の描画結果ではない。

壁面を1 mあたり24分割と64分割で積分し、3点の照度の相対差は最大0.039%だった。ランタンから受光点への直接の線分は3点とも遮蔽される。灯と赤壁の間に仕切りを入れる場合も、赤壁と受光点の間に仕切りを入れる場合も、3点の一回反射成分はゼロとなる。各材質の色はMinecraft 1.21.1のブロック画像を線形化して平均した。計算に用いた候補では、磨かれた深層岩の平均輝度が赤色のコンクリートに最も近かった。実物素材の分光反射率や光束の校正はしていない。[数値と受光点](transport.json) · [積分と遮蔽のコード](reference.py) · [Claudeの設計レビュー](../2026-11-21-carried-light/indirect-advisor.json)

実ゲームでは5面を黒いコンクリートで囲ったランタンの東側だけを開け、東の壁を赤色コンクリート・磨かれた深層岩・黒色コンクリートに取り替えた。カメラはランタンが見えない北の白壁を正面から見る。独立に、ランタンと東壁の間、東壁と白壁の間へそれぞれ石の仕切りを置いた。撮影位置が仕切りに重ならないよう実験室の仕切り位置を少しずらし、その位置で理想的な東壁から届く光がどちらもゼロになることを再計算した。実際の黒色コンクリートは少量の光を反射する。[実験室の構成](fixture.py) · [検証ワールド専用の撮影手順](capture.py)

## 通常プレイと一回反射の実測

中央の受光点は実験室の白壁上の座標 (9.5, 2.5, 0)。同じ11×11画素の平均を載せた。通常表示には露出・環境光も含まれる。診断では同じ配布シェーダーの一回反射だけを出力し、8ビット表示の平方根符号化を戻してから平均した。非常に弱い成分は量子化でゼロになり得る。

| 深層岩・点灯 | 100.5, 87.8, 93.5 | 0.00849, 0.00419, 0.00170 |

### GPUと実ゲームで見つけた角の光漏れ

ランタンの東側も含む六面を不透明な石で完全に閉じたところ、最初のGPU検査では遠くの面の一部が光った。光線が複数のボクセル境界を同時に跨ぐ場合、面を一つずつ渡って光が通れる経路を検査するようにした。修正後は囲いの外の直射・一回反射がともにゼロになり、開口を戻すと光が戻った。実ゲームでも、斜めから見た白壁の同じ範囲で周囲より明るく浮いた点が59画素から0画素になった。各画素の赤・緑が周囲3×3の中央値をともに35階調より大きく上回ることを数えた。[修正前後の拡大画像](corner-fix.png) · [座標と観測範囲](corner-fix.json) · [修正前のGPU出力](gpu-corner-leak-before.log) · [全回帰検査](gpu-final.log)

### 実装と精度

近傍32×32×32ブロックに入る不透明な立方体の各面について、アトラスの色と頂点色から反射率を求める。面に4か所ずつ出射光を記録し、受光面から余弦重み付きの固定96方向で最初に当たる面を探す。受光側は隣接する同一平面の値を補間する。二次光線の長さは12ブロックまでで9ブロックから徐々に減衰する。発光面に直接見通せるかを確かめるときは動く生き物の三角形も扱う。二次光線の遮蔽はブロック形状を使う。葉・色ガラスは厚さに応じて透過する。受光面や反射面が計算範囲を離れると寄与を滑らかに減らす。[面の取り込み](../../release/shaders/lib/bounce_capture.glsl) · [一回反射の計算](../../release/shaders/shadowcomp3.csh)

RTX 3080 TiのOpenGL上で近い赤壁の出射を独立した面積積分と比較し、判定可能な明部でGPU/基準比は0.9994〜1.0000、完全遮蔽に分類できた16面は0だった。白壁の4受光面では同じ比が0.93〜1.23で、有限方向の積分に誤差が残る。光源格子を再配置しても同じ受光面の数値は一致し、松明と魂の松明を合わせた値は単独点灯の和と0.083%以内で一致した。[独立したGPU検査](../../tools/bounce-light-probe.h) · [実測ログ](gpu-final.log)

### 放射輝度の基準

Aqualumen の既存の局所直射は、白い拡散面の出射放射輝度に相当する量を返す。白いブロックを1回照らす表示式は `albedo × lampLighting` で、光源強度11にはこの規約が含まれる。反射面Aから出る光も同じ式を使う。受光面Bでは、余弦重み付き半球に見えるAの出射色の平均を取り、Bの反射率を掛ける。CPUの面積積分にある幾何項の1/πはこの半球平均に対応する。配布版の光源強度に合わせるには `transport.json` の基準値に `11 × (level / 14)²` を掛け、実装の有限半径と距離減衰も考慮する。画面の露出はこの計算の後に適用する。[光輸送方程式と面積形式](https://pbr-book.org/4ed/Light_Transport_I_Surface_Reflection/The_Light_Transport_Equation) · [Irisが渡す面のUV中心](https://shaders.properties/current/reference/attributes/mc_midtexcoord/)

外部シェーダーではPhotonがIrisのUltra設定でボクセル色照明を提供している。Aqualumenでは白い壁を背にランタンを置き、視界の外にある赤い壁を取り替えたときの二次光を個別に測る。[Photon作者による機能説明](https://github.com/sixthsurge/photon/blob/main/README.md) · [前回の同一森林での実画像](../2026-11-21-carried-light/reference-held.jpg)

## Photonとの同じ部屋での比較

Photon 1.1の配布ZIPを同じ検証ワールドの別の複製で使い、Irisの設定で `COLORED_LIGHTS=true` の1項目だけを有効にした。同じ白壁の中央でランタンの点灯と消灯には目で見える差が出た。点灯したまま画面外の東壁を赤いコンクリートから深層岩へ替えたとき、Photonの白壁の赤は115.132から115.124、Aqualumen 1.5.0では145.545から100.545に変わった。両方とも各パックの露出と色調を通したRGB8の測定値で、この部屋・設定での比較に限る。[同一画角の6枚](photon-comparison.jpg) · [色と設定](photon-comparison.json) · [Photonのクライアント記録](photon-colored/complete.json) · [Photon公式](https://github.com/sixthsurge/photon)
