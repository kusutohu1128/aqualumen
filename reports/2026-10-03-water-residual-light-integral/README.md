## Verified controlled result

- Retained production native checks: all 11 program pairs compiled/linked and retained fixtures passed on the RTX 3080 Ti; not a Minecraft FPS measurement.
- CPU light-space integral: six saved raw-vector fixtures at 8x16, 12x32 and 16x64 rules, 18/18 within the unchanged reference gate; maximum component error `1.8689043368e-14`. These are double CPU results, not shader results.
- Actual-main pass-through STUB: genuine numerical/application **RED**, root-owned run exit1, NVIDIA GL4.6 `580.173.02`. Telemetry, all eight cases' 5025-pixel legacy domain, and broad/constant/dark controls passed. The candidate's new applied status was zero everywhere, truthfully.

- First integral implementation: same frozen probe binary, unchanged source width/peak, geometry, inputs and gates; root-owned NVIDIA run exit0/PASS. All eight legacy domains qualify at 5025/5025, new kind1 application is 1 at every ROI point, and all seven control/unsupported diagnostic cases remain 0. The maximum fixed-six component error is `2.8756889422e-9`.
- Independent saved-data audit: 229 telemetry/repeat/passivity/control comparisons pass; 408 source/input/raw digests retained. Fresh raw n/C/v give 643,200 double kernel evaluations, with 5025/5025 finite-rule comparisons passing and maximum component error `8.2414822831e-9`. All 12 candidate fixed-six pure/observer checks against the unchanged converged continuous reference pass. The full ROI comparison is against the finite 8x16 rule, **not a convergence proof at every ROI point**.
- Root CPU tests: 21/21 (9 pack, 2 integral, 4 audit-plumbing, 6 retained inverse mapping). Audit-plumbing tests are not shader evidence. `git diff --check` passes. Existing production pins and dist0.8.6 ZIP remain unchanged; no release was built or installed.
