# 天然の溶岩溜まりを固める

シード308060、`level.dat`だけの新規サバイバルワールド[`world/Aqualumen-Lava-Cavern.zip`](world/Aqualumen-Lava-Cavern.zip)(sha256 `242a7970…`)。地形はMinecraftが一から生成する。保存済みの調査用ワールドと比べると、窓内3,105セル(溶岩197)が完全に一致し、同じ洞窟が再現された。シードはNBTで調査用ワールド・配布zipとも308060と確認した。


面光源版を使い、岩棚まで歩き、魂の松明を置いてから水バケツを使った。保存後に3,105マスを調べ、25マスの溶岩が黒曜石に変わり、松明一本が残った。画像では岩棚に火の青が残り、奥に残った溶岩はその周りを橙色に照らしている。RTX 3080 Ti・1600×900・12チャンクのこの実走で、通常のF3表示43回は12〜20 FPS、中央値14だった。起動直後の固定視点は15〜16 FPSで、初めてシェーダーをリンクしたときはワールド参加から210秒、キャッシュのある実走では2.4秒だった。[変化を撮った三枚](ordered-survival/cavern-light.jpg) · [天然洞窟を歩いた動画](ordered-survival/journey-compact.mp4) · [保存状態・測定条件](ordered-survival/complete.json) · [初回リンクを含む固定視点の計測](split-field-128/complete.json)

## 現場
- スポーン: 凝灰岩の上 (543.5, −52, 376.5)。そこから溶岩の水面(高さ−55)が見える。ピースフル、コマンド不可、ホットバーは空バケツ・水バケツ・ソウルトーチ・石・木のツルハシ/シャベル・パン(9番は素手)。
- 足場: 1段下・1歩北の凝灰岩 (543.5, −53, 375.5)。溶岩の浅瀬 (542,−55,374) まで3.07ブロック。その2〜3ブロック北は溶岩なので、歩きすぎは危険。
- 座標は[`site.json`](site.json)、選定は[`plan.py`](plan.py)。

## 実走(RTX 3080 Ti、私設Xvfb :240〜 + VirtualGL、`:1`と通常Labは未接触、キーボード・マウスのみ)
**歩行版 [`mech180-r2`](mech180-r2/)**(1.8.0): 足場へ歩く → ソウルトーチを (544,−53,374) に置く → 水を (542,−54,375) に置いて溶岩へ流す → 空バケツで水を回収。
- 保存ワールドの差分は、溶岩25セル→黒曜石、ソウルトーチ1個のみ。水セルは空気に戻り、水バケツがスロット0へ戻った(バケツ回収)。
- F3の事前: `Targeted Fluid 542,−55,374 minecraft:lava (falling: false)`、事後: `Targeted Block 541,−55,373 minecraft:obsidian`。
- [比較画像](mech180-r2/comparison.jpg) · [動画(1024px、105秒)](mech180-r2/journey-compact.mp4) · [F3画像](mech180-r2/) · [全記録](result.json)

**低FPS用の歩かない版 [`stay180`](stay180/)**: キー押下は1フレーム単位に丸まるため、1〜2 FPSでは歩行が行き過ぎる。fpsが20未満なら`run.py`が自動でこちらに切り替わる。ソウルトーチを (544,−52,375) に置き、空バケツで天然の溶岩ソース (542,−55,374) を1つ取る。保存ワールドでは`level=0`が`level=2`の流れに変わり、溶岩バケツがインベントリに入った。水を使わないのは、水の設置が溶岩の床(スポーンから5.1ブロック)に届く必要があり、到達距離4.5を超えるため。

## 初期試作での起動と歩行
- `Aqualumen-1.9.0-lava-preview1.zip`は、NVIDIA上でパイプラインが約19分たってもリンクを終えなかった([`probe1`](probe1/)・[`probe2`](probe2/))。別runnerも1000秒で未完と診断しており、パック側の問題とみられる。写真は無い。
- 親がこの`run.py`で`rc2`を試した([`obsidian-rc2`](obsidian-rc2/))。パイプラインは2.4秒で通ったが、洞窟内で1〜2 FPSだったため歩行が止まり失敗した(ワールド変更なし、クリーン終了)。その後、歩行の安全ガードと低FPS版を加えたが、`rc2`は再実走していない。
- 1.8.0の2本はシナリオと状態確認の証明で、新しいシェーダーの画像ではない。FPSは性能測定ではない(私設VGL、上限60、他セッション同時稼働)。

## 再実行
`/tmp/aqualumen-ground-metrics-venv/bin/python3 -I run.py <名前> <pack.zip> world/Aqualumen-Lava-Cavern.zip --video [--cache-from <ドライバキャッシュ>]` → `finish.py <名前>`。私設セッションが2本を超える間は起動を待つ。配布用の天然洞窟は [Aqualumen-Lava-Cavern.zip](../../../dist/Aqualumen-Lava-Cavern.zip) にある。

### 保存した洞窟に戻る

プレビュー3で岩棚を保存し、終了後に同じ保存地点を別のクライアントで開いた。立っていた凝灰岩、25マスの黒曜石、魂の松明が残っていた。松明を回収すると手前の青が消え、奥の溶岩の橙色は残った。同じ場所に松明を置き直すと青が戻った。この二回はゲーム内時刻6000から9490まで連続し、そのうち8513で一度保存・終了した。[再開・回収・再設置の実画面](ordered-return/reopened.jpg) · [再開の入力と保存状態](ordered-return/complete.json) · [プレイを続けられる途中セーブ](ordered-survival/survival-checkpoint.zip)
