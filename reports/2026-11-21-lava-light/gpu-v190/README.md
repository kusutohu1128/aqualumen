# 溶岩光 v1.9.0候補 GPU検証（Claude、独立QA）

対象は `build/lava-v190-src/shaders`（親が作成したGLSL、改変なし）、基準は `dist/Aqualumen-1.8.0.zip`（`release/shaders` と同一）。主判定は RTX 3080 Ti の surfaceless EGL。llvmpipe（ソフトウェア）は独立した照合に使った。どちらも本番GLSLを使った**GPUハーネス**で、Minecraft内の画像やフレーム時間ではない。実行手順は [COMMANDS.md](COMMANDS.md)、数値は [result.json](result.json) にある。

## 結論

**溶岩ゲートは不合格（35項目中4項目）。** 実装上の問題が1件ある。周囲のブロックより0.112低い溜まりの溶岩面で、縁による遮蔽が計算されていない。ゲーム内の溶岩溜まりは通常この形になる。

- 縁が溶岩面の一部を隠す受光点で、GPUは**遮蔽なしの値をそのまま**返す。例として一マス溜まりの壁 (207.5, 175.5, 366) では、GPUの値が0.004352で、独立した面積積分の値は0.002703（遮蔽なしは0.004352）。九マス溜まりの (206.5, 173.5, 366) では、GPUの値が参照の約2倍になった。72受光点の誤差を遮蔽なしの値で割ると、最大は0.38（一マス）と0.51（九マス）、平均は0.11。事前に決めたゲートは最大0.15、平均0.04。
- 推定原因：最初の4サンプル（パッチ内の位置0.25と0.75）が、縁に隠れる帯に入らない。帯はパッチの端から約0.1〜0.7 mの範囲にある。4サンプルの結果が一致すると細分化されない。九マスは1枚の長方形として扱われるので、同じことが起こる。シェーダーは修正していない。修正方針の案は [progress.txt](progress.txt) に書いた。

上記以外の項目はすべて合格した（NVIDIAとllvmpipeで判定は一致）。

## 既存回帰スイートの互換化（ゲートは緩めていない）

未修正の `glcheck` は、候補に対して `lampCellImage must be cleared r32ui holding 64^3 cells` で停止する（llvmpipeで確認）。修正内容は以下。

- `tools/local-lights-probe.h`：`lib/lava_grid.glsl` がないパックでは、従来と同じ厳密なサイズを要求する。ある場合は、拡張後の正確なサイズ（512×2560、128×72、512×2048、16×6912）を要求する。サイズは面光源の規約から算出し、GLSLからは読まない。clearフラグも検査に加えた。生データの全語（拡張部分を含む130万語）の比較はそのまま残した。fieldの比較はセル領域（64³）に限り、溶岩がないときに溶岩近傍数512個がすべて0であることを新しく検査する。
- `tools/entity-light-probe.h`：記録画像を宣言どおりのサイズで確保するようにした。以前は旧サイズに固定していた。
- `tools/glcheck.cpp` と `Makefile`：`--lava-light-probe [基準パック [result.json]]` と `make check-lava` を追加した。`--play-release` では、溶岩を持つパックに限って最後に溶岩プローブを実行する。

NVIDIAでは、候補と `release/shaders` の両方で local / entity / bounce / door / leaf / rain-film の各プローブが exit 0 で終了した。全回帰（`--play-release`）は次のとおり。

- `release/shaders`：exit 0（`PASS normal-play GPU regression checks`）。
- 候補：既存の全検査（太陽・地形・ローカル光・entity・bounce・door・film・leaf）に合格した後、最後の溶岩ゲートで上記の4項目が不合格となり exit 1。

llvmpipeでも同じ判定（31合格・4不合格）になった。受光点ごとのGPU値は、NVIDIAとの差が遮蔽なしの値に対して最大1.4×10⁻⁵。ログは [logs/](logs/) にある。

## 注意

- 計測用ハーネスのGPU時間：`shadowcomp1` は溶岩なしで0.48 ms、溶岩144マスで0.79 ms。受光点あたりの `lampLighting` の値は、転送と読み戻しの時間が大部分を占め、比較に使えなかったため判断に使っていない。どちらもMinecraftのフレーム時間ではない。
- 未検証：Sodiumは明るさに応じて四角形の対角線を入れ替えることがある（未確認）。この場合、平らでない流れの面は今回の前提（0–3の対角線）と少しずれる。Irisでの実際の描画は外部ゲームQAの担当範囲。
- 変異体シェーダーを使った感度試験は、シェーダーの改変にあたるため実施しなかった。
