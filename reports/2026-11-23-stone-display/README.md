# 松明を持ったときの岩肌と樹皮

[実験版ZIP](../../dist/Aqualumen-Diffuse-Display.zip) は Minecraft Java 1.21.1 / Iris 1.8.8 向け。前版の松明の遮蔽計算を引き継ぎ、SDR出力の中間の明るさを調整する。「太陽光と大気」内の「中間調のコントラスト」で 0.0 から 1.0 まで選べる。初期値は 0.4。ビルドは `python3 tools/build.py --diffuse-display`。[岩肌の原寸比較](torch-stone.jpg)

## 同じ岩壁での比較

RTX 3080 Ti、1600×900、12チャンク。隔離セーブで同じ位置・向き・空の時刻に固定し、手ぶら、松明、手ぶらに戻した状態を各3枚撮影した。数値は各材質96点の画面出力を2.2乗で線形化した輝度のP90/P10。大きいほど、測った領域の明暗差が大きい。表に使った手持ち1枚目では、5領域すべてで表示処理に入る色・発光・露出が96点ずつ一致した。初期値の2・3枚目では天井などの一部で表示前の値が異なり、点別の一致数をJSONに残した。左壁の表示比は3枚とも同じだった。露出は2.000。煙やアニメーションで入力が変わる炎粒子は、この表から除いた。

| 松明を手に持った画面 | 元の表示 | 初期値 0.4 | 最大 1.0 |
|---|---:|---:|---:|
| 左の岩壁 | 1.227 | 1.314 | 1.457 |
| 右の岩壁 | 2.903 | 2.880 | 2.859 |
| 天井 | 1.308 | 1.355 | 1.459 |
| くぼみの奥 | 1.112 | 1.112 | 1.112 |
| 壁松明の静止発光部 | 1.191 | 1.191 | 1.191 |

左壁の輝度中央値は元の0.399、初期値で0.400。手ぶらの左壁の明暗比はともに1.847だった。別の夜のオークでは、過去に保存した実ゲームの表示前HDR画像（210×185画素）に同じカーブを適用した。暖色の松明の木目は 1.444 → 1.524、魂の松明は 2.134 → 2.134。樹皮の値は同一入力の再計算。[初期値の測定点と樹皮](default-and-bark.json)・[最大設定](diffuse-and-bark.json)・[岩壁の直接撮影](../2026-11-21-animal-light/woodland/midtones-display-hand-cycle/sample-1-held-0-ingame.png)

Irisのパック設定に0.0を指定した実ゲームの夕方の砂州では、比較元と左右360,000組の出力RGBがすべて一致した。[設定を切った実測](zero-setting.json)

先に輝度とRGB最大値を混ぜて階調を割り当て、色域を超える部分の彩度を下げる案を実装した。左壁は1.582まで上がったが、右壁は1.794、魂の松明の樹皮は1.487まで低下した。配布版には、RGB比を保ったまま表示ピークの0.43〜0.82にのみ作用する区分3次曲線を選んだ。初期値の最大傾きは元の1.84倍、最小は0.72倍。組み合わせた2区間は境界の値と一次導関数が連続する。729通りの色で暗部からHDR 65,504まで各1,024段階を走査し、各色の輝度の単調性と出力範囲を確認した。[最初の試作の記録](stone-and-bark.json)・[GLSL](../../release/diffuse-display/shaders/final.fsh)・[Fableの初回助言](advisor-answer.txt)

## 移動と8ビット表示

松明を持ち、実際のサバイバル操作で岩壁の前を横歩きして戻った。比較元と試作の最終表示を同じフレームの左右に描画し、24 Hzの可逆動画で保存した。比較元で見つけた石の模様を両側で追跡した。数値には手持ち光の実際の変化、画素の再サンプリング、整数画素での位置合わせの誤差を含む。強度ごとの動画は別の歩行で、各動画の左右は同じ入力。[最大設定の追跡結果](motion.json)・[初期値の追跡結果](default-motion.json)・[初期値の可逆動画](../2026-11-21-animal-light/woodland/midtones-display-sidestep/paired-motion.mp4)

| 横歩きで追跡した石の140×96画素 | 元の表示 | 試作の設定 |
|---|---:|---:|
| 初期値0.4の歩行での変化量P95 | 7.31階調 | 8.47階調 |
| 最大1.0の歩行での変化量P95 | 7.09階調 | 12.56階調 |

各歩行で1画素を超えて移動した27組の動画フレームを集計した。元映像との石模様の正規化相関はどちらも全フレームで0.91以上。カメラがほぼ静止した範囲では変化量のP95はすべて0階調だった。

夕方・昼の同じ砂州と、点灯したレッドストーン鉱石・グロウストーンも実ゲームで比較した。各フレームの左右で元の表示と調整後を比較し、下段に空・半透明の手前面・太陽中心のマスクと対数HDRを描いた。晴れた砂州の半透明面の大半は水面。夕方のカメラで太陽中心に当たったのは4点で、昼のカメラの画角には入らなかった。近接画素の色差や飽和も記録した。[実機の昼・夕方・鉱石](default-shore-comparison.jpg)・[初期値の画素集計](default-shore.json)・[最大設定の画素集計](shore.json)

元の8ビット無彩色の全255段差を同じ入力から再計算すると、初期値では8組が同じ階調に丸められ、8組が2階調に広がった。最大設定では19組が同じ階調となり、最大差は3階調。実ゲームでも、夕空の隣接画素で従来の差が1〜3階調だった162,388組のうち、初期値では7,855組の差が0、2,429組の差が4階調以上になった。空でいずれかの色が255に達した画素数は両表示とも9。夜の鉱石の表面4,761画素は同値、隣のグロウストーン表面4,899画素の最大差は3階調だった。

最大設定の砂州テストでは撮影後に親プロセスが終了し、自動の終了証跡が欠落した。3枚のゲーム内F2と原本のSHA-256が一致し、撮影タイムスタンプが検証用のREADYとSTILLの間に入ることを全場面で照合した。元のLabのファイルハッシュ・メタデータも確認した。[個別監査](shore.json)

## GPUとサバイバル

RTX 3080 Ti、2560×1440、12チャンク、白樺林に松明4本。GPUタイムスタンプを使わず、実Minecraftの約10秒間のフレーム間隔を測った。元の表示は以前の同条件の記録を使用した。

| 条件 | フレーム数 | 平均間隔 | P99 |
|---|---:|---:|---:|
| 元の表示 | 121 | 83.19 ms | 88.23 ms |
| 最大設定の試作 | 121 | 83.07 ms | 89.23 ms |
| 配布版の初期値0.4 | 121 | 82.90 ms | 89.55 ms |

平均はどれも約12 fps相当。0.29 msの差は各1回の観測で、速度改善の根拠には使っていない。配布ZIPと比較元の差分は最終フラグメントシェーダー、設定画面、英語と日本語の表示名。最終プログラムをNVIDIAとMesaで個別にコンパイル・リンクした。[計測と配布物の照合](verification.json)・[配布版初期値のフレーム記録](../2026-11-23-torch-density/gp-density-midtones-default/summary.json)

元のセーブから分岐した通常のサバイバルで、当初の輝度カーブを使い、既存の壁松明の左隣（598, 72, 425）の石を木のツルハシで掘った。一段奥の石、取り付けた松明、魂のランタン、林からの道しるべをセーブのチャンクから確認した。9.54 m歩き、ワールド時計は1,286ティック進んだ。3シードの連続したセーブに記録された経過時間は4.0223ゲーム日、移動は990.02 m。固定視点の比較・診断動画はこの進捗に加えていない。[再開用セーブ](../../dist/Aqualumen-Widened-Torch-Niche.zip)・[確認したブロック](../2026-11-21-animal-light/woodland/stone-display-wider-camp/save.json)・[累積の内訳](playtime.json)

Fableと再検討し、滑らかな勾配と歩行中の変動を理由に、この調整は選択式の実験版とした。元のLabで選択中のシェーダーは1.8.0。実機テストはいずれも別のゲームディレクトリで行った。[Fableの再評価](advisor-followup.txt)
