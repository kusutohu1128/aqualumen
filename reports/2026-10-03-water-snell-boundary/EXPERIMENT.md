# Exact-input Snell boundary — predeclared experiment

Previous reason observation is real progress: it implemented a passive
observer and changed the next action using actual mixed Iris failures. It did
not implement an optical fix. Its frozen553-file packet remains untouched.

## Ranked hypotheses and distinguishing observations

1. Unsupported forward branch: an independently reconstructed forward ray has
   no downward, front-facing facet mapping to that air target. Its absence must
   be proved geometrically, not inferred from a failed float predicate.
2. Critical cancellation: exact binary32 inputs have positive supported
   discriminant but a faithful binary32 parent expression gives zero/negative
   discriminant. A stable equivalent must reconstruct the same branch without
   changing raw observed v, eta, epsilon or visibility.
3. Reconstruction instability: support is positive but the cancellation-prone
   square root makes forward reconstruction exceed the fixed existing bound.
   Independent high precision plus explicit host float replay separates this
   from an absent branch. A double control using the same old predicates is
   not the independent oracle.

## Fixed inputs, public seam and acceptance scope

Use eta bits0x3faa9fbe, the actual GLSL1.333 literal, not Python double1.333.
First family: target(0,1,0), view.y=binary32(-1/eta±2^-j),j12..20;
view.x=binary32(sqrt(1-view.y²)),view.z0. These raw vectors are not renormalized.
Reference precision80/120digits; normalize only the explicitly generated light
direction, recording its original bits/norm and the normalization policy.
An explicit nonfused nearest-even replay and separately labelled fused
operation variants are controls, not actual NVIDIA execution.

The up-target boundary makes a nearly horizontal facet and may have vanishing
Gaussian power or fail the legacy reflected-world hemisphere. Thus add a
predeclared tilted family using view.y=binary32(-.95),
view.x=binary32(sqrt(1-.95²)) from the declared double .95 construction,
negative-x upward targets whose dot with raw view is near -k/eta, offsets
±2^-j,j12..20. Require the positive critical case to have finite positive
Gaussian slope measure, meanNormal.y<-.5 and reflected.y<0 before attributing
relevance to the current complete cap model. No target/coordinate search or
post-result threshold selection.

Public pure math shader function `waterSnellNode(view,generatedTarget,eta)`
returns facet, transmitted ray/cosine, facing, Jacobian, transmission and
support/invalid status. It is initially tested through a CPU-only C++ wrapper
that includes the literal GLSL function, not a separately copied candidate.
Normal-incidence tracer→positive-supported critical numerical RED→minimal
stable formula→absent/invalid controls are incremental TDD slices. Missing
interface/build RED is a tooling RED, not an optical failure. No candidate
integration into shipping/cap policy until independent reference comparison.

Six previously fixed native-cap-v1 actual n/v/C samples and their48 Sun nodes
are positive interior controls, not actual Iris boundary inputs. Retain the
original absolute2e-6/relative2e-4 C0 gate and2e-8/2e-6 refinement gate where
qualified. Old water/reflection/base/fallback/covariance/receiver policy is
unchanged in this experiment. Stable pure math is not automatically a change
to whole-source zero-support or reflection admission.

## Requirements deliberately not claimed

Actual Iris ten category2/two category4 points still lack raw n/v/Sun/targets;
the present data does not prove those points share this numerical failure.
Native GPU, real-Iris application, full-frame fish-eye/rim/motion, pixel-AA,
physical energy/reciprocity and shipping acceptance remain required. The
ordinary client stays paused; CPU agents do not own GL/game. No old frozen
report or ordinary world is modified/restored. The full realism goal stays
active.
