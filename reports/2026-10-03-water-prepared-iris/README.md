# Prepared-view reuse: actual Iris checkpoint

水の計算結果を変えず、視点・屈折率の共通計算を48回のループ外へ移す
TEST版を、実際のMinecraft/Irisで検証した記録です。通常版への採用では
ありません。水中の細い黒帯・角ばった縁は残っており、修正完了ではありません。

同じ900p設定・水中3視点の旧版→新版テストでは、平均FPSが次のように
変わりました。13〜18FPSは重い検証用パックの値で、通常版の値ではありません。

| 視点 | 旧版 → 新版 平均FPS | 観測された増加 |
| --- | ---: | ---: |
| 浅い水中・真上 | 13.40 → 14.97 | 11.66% |
| 深い水中・真上 | 11.74 → 13.33 | 13.57% |
| 浅い水中・斜め上 | 15.67 → 18.28 | 16.69% |

1組の順次測定であり、一般的な高速化率・60FPS下限・GPUだけの速度向上を
保証しません。元パックを内包するため、毎回のZIP読込・ハッシュ計算量も
変わっています。詳細は[独立測定監査](runtime-physical-audit.md)を参照。

公開CPUテスト13件と既存GPUチェックは通過。実機で選んだ16地点の観測は
旧版と512成分すべてbinary32一致し、理由別集計も維持しました。浅い真上・
斜め上の旧新版PNGはファイル全体で一致。深い場面は粒子などが異なり、
全画面の一致や物理的正しさを受け入れたわけではありません。

通常0.6/physics0.2へ復帰し、普段のワールドを実際に開いて21:55:02の
一時停止画面を確認しました。TEST Mod/観測は無効化済み。通常ワールドの
バックアップを上書き復元していません。
