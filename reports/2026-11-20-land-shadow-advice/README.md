# 陸上影プレビューの再評価（2026-11-20）

陸上影プレビューは、制御した形状で光漏れと斜面の自己影を改善した。通常版への採用判断には、ゲーム内で日が当たる地面と、そこに落ちる影の比較が残る。Claude Opusに現行コードと保存資料を読み取り専用で評価してもらい、Codexが指摘を実装と撮影記録に照合した。[Claudeの助言](advisor.md) · [実行記録](receipt.json)

**今回照合したもの。** Labの通常版とプレビューのZIPは保存版とそれぞれ一致した。陸上影のGLSL 2本もプレビュー内のものと一致し、過去の検証記録15件と実ゲーム撮影の各26ファイルのハッシュを確認した。Labは停止中で、通常版0.6を選択、physics 0.2.0、ベンチマーク無効だった。

**実測で言えること。** 保存されたRTX 3080 Tiの結果では、厚さ1cmの板を床から4cm浮かせたテストと、中心から離れた60度の斜面のテストで、それぞれ旧版が誤判定した16,641画素が候補ではすべて期待値を満たした。全26ケースが合格した。今回再確認したゲーム画像6枚では、どちらの版も逆光の壁が奥の標的を隠し、壁を外すと標的が見えた。逆光側の壁の暗さは面の向きだけでも説明できる。順光側では壁に影を落とす物体を配置していない。画像と撮影記録からは、対象画素で新方式を使ったか、接地する影を改善したかを判別できない。[元の実測と画像](../2026-10-23-land-shadows/README.md)

**助言を踏まえた判断。** 低い太陽で段差に出る黒い筋、ブロックと影の間の明るい隙間、時間とともに跳ぶ影の縁を優先する。いずれも候補で再現済みの不具合ではない。Claudeが指摘した太陽・月の影関数は、展開ソースでは同じ引数で2か所から呼ばれる。実際の追加コストは未測定。60度の形状で最大約24mmの深度差があったのは影マップ中央をまたぐ特定のテストで、余裕を全地形で一律8mmとみなす根拠はない。

比較するなら、隔離TESTワールドで石の段差と地面に接する柵の影を同じ画角に入れる。通常版と候補でカメラ・天候・時刻をそろえ、正午と夕方の静止画、同じ開始時刻から太陽が進む短い動画を保存する。候補と同じ計算を使う診断表示を別撮りし、比較する地面で新方式が動いたかを確かめる。ほぼ光と平行な面などでは旧方式への切り替えが設計されているため、画面全体を新方式にする必要はない。通常表示で根元の光漏れが減り、新しい筋やちらつきが増えなければ、採用の判断材料とする。1440p・12チャンクでのフレーム時間は別途比較する。
