# 白樺林の松明を、画面に残る地形で計算する

手持ち灯の半影を改善した版では、松明を4本置いて両手を空にした白樺林でもフレーム時間が増えた。RTX 3080 Ti、Minecraft 1.21.1、2560×1440、12チャンクのGPUプロファイラで調べると、プレビュー12相当から増えた6.10 msのうち、切り抜き地形が2.70 ms、不透明地形が1.63 ms、反射面から出る光を計算する `shadowcomp2` が1.78 msだった。数値は各区間で観測した時間で、レジスタ使用量や命令キャッシュは測っていない。[元の実験版と画質](../2026-11-23-torch-penumbra/README.md)・[各GPU区間](profile.json)

松明のある区画で溶岩面の候補がない場合、試作は地形の色・法線・水膜・ブロック光を既存のG-bufferに書く。カメラに最も近い不透明面が決まった後、最終深度から位置を戻し、その面で照明を計算する。葉の穴の奥に別の面が見える場合、そのピクセルには手前の葉の光を加えない。手持ち灯の面積計算、動物による遮蔽、葉の透過、二回反射、画素数は比較元と同じ。水面や動物が受ける光は各描画プログラムで計算する。[試作のソースと再現ビルド](visible_pack.py)

## 白樺林でのフレーム時間

| 1440p・松明4本 | プレビュー12相当 | 手持ち灯の半影・前方描画 | 同じ半影・最前面で計算 |
| --- | ---: | ---: | ---: |
| GPUフレーム平均 | 67.06 ms | 73.16 ms | 61.18 ms |
| 切り抜き地形 | 24.80 ms | 27.50 ms | 10.92 ms |
| 不透明地形 | 11.68 ms | 13.30 ms | 4.77 ms |
| 遅延描画全体 | 1.92 ms | 2.01 ms | 15.47 ms |
| 反射面から出る光の計算 | 5.86 ms | 7.65 ms | 7.70 ms |

GPU計測を外し、最前面版→前方版の順に同じ場所を再収録した。平均フレーム間隔は最前面版66.76 ms・前方版79.73 ms、p99は70.58 ms・83.62 ms。最前面版でもこの場面は平均で約15 fps。各条件はF2撮影後の3バッチを除いた連続10秒以上で、サーバー側で視点、両手、4本の松明と支持面を収録前後に照合した。[GPU計測](profile.json)・[逆順のフレーム間隔](intervals.json)・[4本と周囲の地形](../2026-11-23-torch-density/gp-density-visible-terrain/geometry.json)

設置灯に照らされた樹皮57,350画素は、GPU計測あり・なしのどちらでもチャンネル差が最大1階調だった。炎・水面・雲には撮影時刻による変動がある。各方式の6枚で見たチャンネルごとの最小～最大に重なりがある場合を差0と数えると、全画面で8階調を超えて範囲が離れたのは5画素だった。全6枚でRGBの各チャンネルが1階調以内に収まる画素に絞ると、両方式でこの条件を満たす3,406,769画素のうち2画素が8階調を超え、最大差は10階調だった。各方式の6枚で同じ画素が違う色を取り得るため、この比較だけで前後の描画の一致を判定することはできない。[画素の照合](persistent-pixels.json)・[集計方法](repeatability.py)

## 柱と2色の灯りを横切る牛

1280×720の同じ室内の12段階を通常描画で収録した。松明を持って柱の横に立つと、壁を1 cm進んだときの最大の輝度段差は左の主な縁で1.28→1.21階調、右で1.00→1.00階調。登録した壁の8,495地点と25,292地点で前方版とのRGB差は最大1階調だった。牛は4.44 m歩き、戻った壁の色は前方版190.03/175.29/162.82、試作190.03/175.29/162.84だった。柱を照らした状態で約2秒ずつ測った平均フレーム間隔は左で10.54→11.84 ms、右で10.58→11.81 msになった。白樺林より軽いこの室内では遅延描画の費用が増えた。[壁の縁の実画面](room-edges.png)・[数値とフレーム番号](room-quality.json)・[実ゲームの動画](frontmost-room/crossing.mp4)

Claude Fable 5.2 HighをDevin CLIから呼び、画素が二重に照らされるか照明から外れる条件を尋ねた。Fableは同一フレームで最終表示前の光を比べながら、手持ち松明で設置松明のそばのブロックを掘る操作を挙げた。手、ひび割れ、選択枠、破片、ドロップ品が同じ視野に入るからである。[質問](advisor-question.txt)・[回答と仮説](advisor.txt)

## 松明の支持ブロックを掘る

前方描画で計算したRGBを別の浮動小数点テクスチャに保存し、同じフレームの同じ地形画素について、最終深度から計算したRGBと比較した。前方描画で局所光を外したか、遅延描画で実際に加えたかも別々に記録した。診断の単位は露出・表示変換前の線形RGBで、誤差は3チャンネルの絶対差の最大。実装上、この観測点より後に合成する透明面の寄与は含まれない。[診断用パックの生成](meter.py)・[数値の読み出し](analyze_meter.py)

湖畔のサバイバルセーブを隔離して開き、松明を手に持ったまま、壁付け松明を支える上段の土を掘った。4秒の可逆動画120コマのうち、計器の値が異なる78画面を採用した。画面全体を縦横2画素おきに読み、HUDの照準が重なる隅16×16画素と校正行を除いた。掘っている場所は別のパネルで480×240画素を間引かずに読んだ。照明を移した地形8,791,896サンプルで、二重加算・加算漏れはともに0。線形RGBの差は99%が0.00130以下、最大0.01449で、0.01を超えたのは26サンプルだった。照準の周囲で比較できた1,991,366サンプルはすべて0.00074以下だった。これは時間方向に同じ地形を含むサンプル数である。[採掘時の集計](mining-meter.json)・[実機の操作と保存結果](../2026-11-21-animal-light/woodland/count-lit-surfaces-r3/complete.json)

## 雨の丸石と葉の切り抜き

別の隔離ワールドで屋根を開け、雨の夜にランタンと魂のランタンを点けた。雨・葉・牛・床・視点をゲーム内で照合した3段階を各3枚収録した。9枚とも地形の照明の二重加算・加算漏れは0。葉と牛のあるF2画像では、濡れた地形97,509、葉3,524、エンティティ6,507サンプルを区別できた。濡れた地形での線形RGB差は中央値0.0000474、99%点0.00550、最大0.02396。9枚全体での最大は0.03094だった。濡れた石の鏡面反射を前方描画と同じ精度で再現できるかは引き続き課題である。[各段階・材質の差](wet-meter.json)・[雨と遮蔽物の配置](wet-ownership/geometry.json)

[実験版ZIP](../../dist/Aqualumen-Visible-Terrain-Study.zip) のSHA-256は `0fd89fc4c8b3d638f6bc270c450d772817564559a4690cae01c10de78bd73a36`。実機で試した通常描画パックとバイト単位で一致する。手持ち松明の半影版から内容が変わるのは139エントリ中 `shaders/lib/local_lighting.glsl` の1件。ワールド座標ごとの静的な松明キャッシュは今回の時間短縮に含まれない。診断用のテクスチャと動画収録は隔離検証でのみ使用した。

通常描画の実験版でも元の湖畔から同じ操作を行った。4秒の画面で上段の土にひびが伸び、土の破片と外れた松明が見えた。下段の土に松明を立て、砂州から照らし方を見直して終了した。保存したチャンクでは新しい位置に松明、以前の壁付け松明の位置に空気があり、隣の魂のランタンも残っている。継続セーブに加えたのはこの通常描画の1,186ティック・9.37 m。合計は3シードで76,891ティック（3.20379ゲーム日）、833.54 m。診断用の複製はこの合計に含めていない。[通常描画4場面](lowered-torch.jpg)・[保存ブロックの照合](../2026-11-21-animal-light/woodland/lower-shore-torch/save.json)・[プレイ記録](playtime.json)・[隔離セーブZIP](../../dist/Aqualumen-Low-Shore-Light.zip)

診断パックの初回はIrisによるクリア色の解釈で初期化に失敗した。4成分で明示し、次の試行でゲーム内の校正値を確認した。録画起動時のFFmpeg引数を直した3回目で採掘の収録と保存まで完了した。掲載した診断値はこの完了分と雨の試験から取った。Mesa llvmpipeでも通常版と診断版それぞれ21組の描画プログラム・13個の計算プログラムのコンパイルとリンクを確認した。[通常版のコンパイルログ](compile-normal-mesa.log)・[診断版のコンパイルログ](compile-diagnostic-mesa.log)
