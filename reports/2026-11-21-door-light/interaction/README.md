# レバーで扉を開閉する実プレイ映像

Aqualumen 1.6.0-door-rc3（SHA-256 `ed189bb2…baf414`）を、RTX 3080 Ti（OpenGL `NVIDIA GeForce RTX 3080 Ti/PCIe/SSE2`）の通常クライアントで録画した。夕暮れの2部屋の家で、サバイバルのプレイヤーが部屋Aの床に立ったまま、扉の隣の壁レバーを実際のマウス右クリックで4回切り替えている。

**[28.8秒の映像 `lever-r2/lever-door.mp4`](lever-r2/lever-door.mp4)**（1600×900、H.264、865コマ。コマ数は録画の周期であり、ゲームの描画性能ではない）

## 場面

- 家は既存の `../house.py` の2部屋の家。レバーは部屋A側 (410, 162, -405)、ステートは `lever[face=wall,facing=west]`。取り付け先は扉の上半分 (411, 162, -404) に隣接する濃色の原木の柱 (411, 162, -405)。
- 暖色ランタンは部屋B、ソウルランタンは部屋Aに両方置いてある。ただしソウルランタンは構図に入っていない。
- プレイヤーは (408.0, 161, -406.7) に立つ。レバーまで3.33 m（到達距離4.5 m以内）で、十字線がレバーの中心にある。
- 順序は 閉 → 開（クリック1）→ 閉（2）→ 開に戻す（3）→ 閉（4）。各状態はサーバーの確認後に5.5秒保持した。

## 実イベントの証拠

- 右クリックは `xdotool` の XTest によるボタン3の押下・解放。実行前に、自分のJavaプロセスのウィンドウにフォーカスがあり、ポインタもそのウィンドウ上にあることを毎回確認した。違えば拒否する（ドライランで試験済み）。録画前にウィンドウ捕捉用の中クリックを1回だけ送った。サバイバルでは効果がない。
- データパックは家を最初に一度だけ建てる（扉は閉、レバーはオフ、両ランタン設置）。以後は `execute if block` で監視するだけで、扉とレバーには書き込まない。`check_datapack` がこれを静的に検査する。
- サーバーは毎ティック、レバーと扉の上下半分の状態を判定し、変化時と10ティックごとに `AQDI_S` を記録する。[生ログ](lever-r2/server-events.log)

| クリック | サーバー署名 | 内容 |
| --- | ---: | --- |
| 1（開） | 96→127 | レバーON、扉の上下半分とも `open=true,powered=true` |
| 2（閉） | 127→96 | すべてオフ・閉 |
| 3（開） | 96→127 | 同上 |
| 4（閉） | 127→96 | 同上 |

- 各クリックから状態確認までの遅れは0.10〜0.11秒（読み取り側の観測値）。レバーと扉の両半分は同じティックで切り替わった。
- 録画中の62サンプルで、プレイヤー位置のずれは最大0 mm、視線のずれは最大0.01度。接地は常に1。DRIFTやFAILはなし。
- 元のセーブとLab設定のハッシュは実行前後で一致。元のLabのウィンドウには触れていない。専用の複製ワールドの正確なUUID・シードを確認した。通常Modは3つで、記録用Modはなし。Irisのシェーダー退避もなし。

## 表示への効果（動画から読んだ値）

床の15×15画素の平均（sRGB 8ビット、3チャンネル平均）。露出の自動調整と動画圧縮を含む。

| 領域 | 閉（各保持の終わり） | 開 | 備考 |
| --- | ---: | ---: | --- |
| 扉の手前0.6 m（扉軸上の床） | 104.4 | 133.0 | 開閉で2回とも同じ値に戻る |
| 扉軸上の床、1.2 m先 | 108.6 | 129.7 | |
| 扉軸上の床、2 m先 | 124.7 | 124.7 | 変化なし |
| 扉脇の床（対照） | 103.5 | 103.4 | 変化なし |

開いた映像では扉の前の床に明るい筋が現れ、閉じると消える。[各状態のフレーム](lever-r2/frames/)。全測定は [complete.json](lever-r2/complete.json)。

## 未検証・制限

- 動く動物（牛）による二つ目の撮影は行っていない。生き物の影に関する主張は、牛の位置の実測と光の遮蔽の実測がないため、未検証のままにする。
- この映像のコマ数はゲームのフレーム時間ではない。
- 失敗した最初の試行 [lever-r1](lever-r1/) は保存した。原因はプレイヤーの座標が整数で書かれてブロック中心 (+0.5) に補正され、x=408.5 に立ったこと。座標を小数表記にして `lever-r2` で解決した。

## 再現

```
python3 capture.py --dry-run
python3 capture.py ../../../dist/Aqualumen-1.6.0-door-rc3.zip <出力名>   # /tmp/aql-render21-1000.lock を使用
```

進行は `status.json` に書き出される。
