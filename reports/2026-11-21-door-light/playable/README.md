# Aqualumen Lantern House（遊べるショーケース・ワールド）

Minecraft Java 1.21.1 / 通常の Aqualumen 1.6.0 用の、新規・単独のクリエイティブ・シングルプレイ・セーブ。

- 配布物: `dist/Aqualumen-Lantern-House.zip`（最上位フォルダ `Aqualumen-Lantern-House/` に `level.dat` と `region/*.mca` のみ）
- 生成: `python3 -I build_world.py <out>` → `python3 -I package.py <world> <zip>`（標準ライブラリのみ、オフライン）
- 検証: `python3 -I validate_world.py <world> --zip <zip> --json validation.json --map`（独立した NBT/Anvil デコーダ）
- ネイティブ煙テスト: `smoke.py`（使い捨てコピー、レンダーロック下で 1 回だけ）

## 中身
- `../house.py` の二部屋の夕暮れの家（同じ 2 つのランタン、手動で開閉できるダークオークのドア）。地面と同じ高さの床・
  丸石の基礎で地面に埋め込み。北側（正面）に外から入れるドアを 2 つ（部屋 A / 部屋 B）、石レンガのポーチ、土の道。
- 本物のオーク / シラカバ 6 本。西側の木が長い影を道とたいまつの木に落とす。たいまつは 1 本だけ、スポーンから見える
  オークの幹（北側）に付いている。道の脇に、たいまつを置いて壊せる広い芝生。
- 看板は 2 枚だけ（日本語・バニラ）。ドアは右クリックで開閉。
- 時刻 11800 固定（`doDaylightCycle=false`、ワールド設定として通常のゲームルールのみ）。天候サイクルと mob スポーンも
  無効。クリエイティブ、コマンド不要（チート無効）。ホットバー: たいまつ / ランタン / ソウルランタン / ダークオークのドア /
  板材 / 石レンガ / 苗木。
- データパック、コマンドブロック、ファンクション、テスト用 MOD、UUID マーカー、プレイヤー UUID は一切なし。

## ネイティブ煙テスト（使い捨てコピー、NVIDIA RTX 3080 Ti、Aqualumen-1.6.0.zip 公式ハッシュ）
- `smoke/`: スポーン → 玄関ドアを右クリックで開ける → 部屋 A に入る、の 4 枚（`01-spawn.png` 他）と `smoke.json`。
  ログのエラー 0、正常終了、保存されたコピーで玄関ドアが open=true。
- `smoke-attempt1/`: 失敗した 1 回目（Iris のパイプライン構築約 104 秒を待たなかったスクリプト側の問題。ワールドは正常）。
- 初回起動はシェーダーコンパイルで約 100 秒 画面が止まって見えます（コールドキャッシュ時）。
