# Minecraft 実機の GPU パス計測

Iris 1.8.8、Sodium 0.6.9、Minecraft 1.21.1 の描画キューに OpenGL の時刻印を打ち、どの描画や計算に時間がかかるかを調べた。対象は RTX 3080 Ti、2560×1440、描画距離 12、垂直同期オフ、120 FPS 上限。専用 Xvfb に VirtualGL の EGL 経路で描画した。ワールドはシード 308060 の AqualumenNaturalV2 の私有コピー。両場面は同じカメラ、同じ牛 1 頭で、夜は屋根のある白い部屋にランタン 2 個、正午は屋根を開けて両方とも消す。

較正は **4.010 倍**で合格。通常の p7 で GPU 観測を有効にすると正午の CPU フレーム間隔が平均 **3.335%**、p95 で **5.107%** 長くなり、両方の上限を超えた。ここでキャンペーンを停止した。2 灯の夜に計測した p7 では不透明地形の描画が中央値 **8.713 ms**、影取得後の shadowcomp ステージが **4.343 ms** だった。正午はそれぞれ **2.400 ms** と **0.554 ms** で、prepare ステージが **3.344 ms** を占めた。両場面では照明のほか屋根と時刻も変わるため、単一ランプの追加コストは算出できない。

## 計測範囲と読み方

- GPU 全体は Minecraft の描画開始から、最終フレームバッファ転送後、ウィンドウ交換直前までの経過時間。GPU へのコマンド供給が途切れた時間も含み得る。GPU 稼働率や、VirtualGL 転送だけの時間は求めていない。
- 各プログラムには Iris のソース名を付けた。外側のパスにはバインドやバリアも含む。内側には実際の dispatch・全画面 quad・バリアの時刻がある。影の地形とエンティティのバッファ描画、画面側の Sodium 地形 3 種とエンティティの一括描画も記録する。透過地形にはガラスと水が共存する。エンティティの種類、手の描画、個別の光線、頂点とフラグメント、レジスタ使用量は分解できない。
- 親子の行は時間が重なる。フレームごとに同名の呼び出しを合計し、直下の子を引いた排他時間と最上位範囲の間の未分類時間を別に集計する。中央値と p95 は nearest-rank。未分類率は対象フレームの未分類時間の合計を GPU 全体の合計で割る。場面中に一度も出ない範囲は未観測とする。
- CPU 側のフレーム間隔は既存のフレーム観測器が描画関数から戻った時刻の差。ウィンドウ交換を含む。F2 撮影後の 3 バッチを除き、次の連続 10 秒以上を発行時のフレーム番号で結び付ける。glcheck の合成シェーダー実行時間は今回の数値には含まない。
- GPU 時刻印は 16 フレーム分を循環使用し、8 フレーム後以降に完了を確認して 64 ビットで回収する。未完了なら読み飛ばし、使用中のスロットは再利用しない。番号が欠けた窓、再読み込みをまたぐ窓、0.02 ms を超える収支誤差は棄却する。

## 較正と観測負荷

夜の shadowcomp4～7 の dispatch 時間は、同一フレームで合計した後の中央値で 6.7379 ms。通常のプレビュー 7 の shadowcomp4 は 1.6804 ms で、比は **4.010 倍**（許容 3～5 倍）。毎フレーム各プログラムを 1 回実行した。

| 夜の対照 | 較正 ZIP | p7 | 絶対差 | 許容差 |
| --- | ---: | ---: | ---: | ---: |
| prepare2 dispatch（ms） | 0.2140 | 0.2130 | 0.0010 | 0.1000 |
| final quad（ms） | 0.1843 | 0.1833 | 0.0010 | 0.1000 |

固定した天井の 21×21 画素（左上 1270,70）の平均 RGB は、2 枚の F2 間で最大 0.0000 コード差（許容 1）。対照パスの許容差は max(0.10 ms, 基準の 10%) とした。較正の総合判定は **合格**。[較正 F2](runs/gp-cal-4x-c/both-west-ingame.png)・[通常版 F2](runs/gp-p7-a/both-west-ingame.png)

## 検証と保全

初回はワールド参加中の再帰描画、2 回目は空の shadowcomp スロットで停止した。どちらも受理フレームは 0。空スロットの回帰テストで同じ NoSuchElementException を再現し、修正後は空・未登録・既知のソースをすべて処理できた。コールバック例外を注入するテストでは 1 件を記録し、その後のコールバックを無効化した。[初回ログ](runs/gp-cal-4x/client.log)・[2 回目のログ](runs/gp-cal-4x-retry/client.log)

使用した GPU 観測 JAR の SHA-256 は `75d6e7307d9437c3aa165d25530878ea7f42456644e7112713728cc2c918ea20`、CPU 観測 JAR は `636e71f6ad232cc0719391008612871d58c05d38cea8a39f8fbd0f7bc1c614fb`、較正 ZIP は `63b69616e9332484b7a7ce44c5b05bdb6e39a476452a6ba2a71b4b20f6acf6d0`。NVIDIA GeForce RTX 3080 Ti/PCIe/SSE2、OpenGL 3.2.0 NVIDIA 580.173.02、64 ビット時刻印。使用中のプログラム、描画・読取 FBO、VAO、アクティブテクスチャのバインドを確認した。計測ありの各実行で 8 クラス・51 命令位置がオフライン検証と一致し、各クラスへの適用は 1 回だった。

各起動前と描画ロック内で nvidia-smi と ps を確認し、ジョブを 1 件ずつ実行した。Lab の通常 5 ファイル、無効のコンパイラ、p7、p8 の計 8 SHA-256、全項目のサイズ・更新時刻の集約値、元ワールドの内容が前後で一致した。Lab の選択は 1.8.0、physics 0.2.0 は有効、lighting compiler 0.3.0 は無効。使用した 2 回の GPU 計測でスロット・キューのドロップおよびフック例外は 0 件。生 CSV、ビルドした JAR・較正 ZIP、ドライバーキャッシュは build/gpu-profiler に保存した。[較正の環境記録](runs/gp-cal-4x-c/preflight.json)
