# Minecraft 実機の GPU パス計測

RTX 3080 Ti、2560×1440、描画距離 12 で、1.8.0 とプレビュー 3、プレビュー 7 と 8 をそれぞれ ABBA 順に比較した。GPU 時刻印で描画区間を、クライアントの描画復帰間隔でプレイヤー側のフレーム時間を測った。Iris 1.8.8、Sodium 0.6.9、Minecraft 1.21.1、垂直同期オフ、120 FPS 上限、専用 Xvfb と VirtualGL/EGL を使用した。

**溶岩がない白樺林でも、p3 は消灯時に遅くなった。** 1.8.0 からの GPU フレーム中央値の差は A +4.112 ms、逆順の B +5.912 ms。平均フレームで寄与を加算すると全体 +5.036 ms のうち、deferred が +1.434 ms、composite が +1.389 ms で、全画面の 2 ステージが 56% を占めた。可視地形は cutout +0.880、translucent +0.592、solid +0.325 ms、shadowcomp は +0.393 ms。CPU 平均フレーム間隔の組内差は +5.249 ms（−8.52 FPS）。旧記録の消灯 44.3 → 33.0 FPS とは別のサンプルで、低下の方向が再現した。p3 の composite.fsh 本体は 1.8.0 と同じだが、展開される local_lighting.glsl が異なる。測定は時間が増えたプログラムを示す。レジスタ圧や occupancy 低下を示すカウンターは取得していない。[以前の 1.8.0](../2026-11-21-lava-light/wall-v190/birch-stable/timing.json)・[以前の p3](../2026-11-21-lava-light/wall-v190/birch-preview3-final/timing.json)

**松明 1 本の増分は、可視地形の描画と影取得後の計算に集中した。** 同じ白樺のカメラで消灯 → 松明にすると、1.8.0 の平均 GPU フレームは +11.551 ms。内訳は cutout +4.006、solid +2.314、shadowcomp +5.173 ms。p3 は全体 +9.787 ms のうち順に +3.991、+2.278、+3.566 ms だった。CPU 平均間隔の増分は 1.8.0 が +11.781 ms、p3 が +9.926 ms。地形の時間だけで松明のコスト全体を説明することはできず、個々の遮蔽光線も分離していない。

白い部屋の平均 GPU フレームは p3 で夜 +0.455、正午 +2.118 ms。夜は composite +1.414、main/entities +0.636、deferred +0.299 ms に対し、shadowcomp が −1.849 ms で相殺した。正午は composite +1.284 ms が最大。両版の室内で main/entities の送信は 1 draw/フレーム、flush 呼出は 2 → 5 回で、別描画設定の差も含む。屋根・時刻も変わる室内の夜と正午からは、ランタン単独の増分を求められない。

p8 − p7 の GPU フレーム中央値の組内差平均は夜 +0.204、正午 +0.143 ms。A / B 別では夜 +0.366 / +0.042、正午 +0.278 / +0.008 ms。変更対象の final quad は両場面・両順序で +0.01536 ms、露出を更新する composite3 dispatch は夜 0.000、正午 −0.001 ms。CPU 平均間隔は夜 +0.233、正午 +0.075 ms。パック全体の差は組によって変わる。露出処理の寄与として実測できたのは、この 2 プログラムの所要時間の差である。

## 計測範囲と読み方

- GPU 全体は Minecraft の描画開始から、最終フレームバッファ転送後、ウィンドウ交換直前までの経過時間。GPU へのコマンド供給が途切れた時間も含み得る。GPU 稼働率や、VirtualGL 転送だけの時間は求めていない。
- 各プログラムには Iris のソース名を付けた。外側のパスにはバインドやバリアも含む。内側には実際の dispatch・全画面 quad・バリアの時刻がある。影の地形とエンティティのバッファ描画、画面側の Sodium 地形 3 種とエンティティの一括描画も記録する。透過地形にはガラスと水が共存する。エンティティの種類、手の描画、個別の光線、頂点とフラグメント、レジスタ使用量は分解できない。
- 親子の行は時間が重なる。フレームごとに同名の呼び出しを合計し、直下の子を引いた排他時間と最上位範囲の間の未分類時間を別に集計する。中央値と p95 は nearest-rank。未分類率は対象フレームの未分類時間の合計を GPU 全体の合計で割る。場面中に一度も出ない範囲は未観測とする。
- CPU 側のフレーム間隔は既存のフレーム観測器が描画関数から戻った時刻の差。ウィンドウ交換を含む。F2 撮影後の 3 バッチを除き、次の連続 10 秒以上を発行時のフレーム番号で結び付ける。glcheck の合成シェーダー実行時間は今回の数値には含まない。
- GPU 時刻印は 16 フレーム分を循環使用し、8 フレーム後以降に完了を確認して 64 ビットで回収する。未完了なら読み飛ばし、使用中のスロットは再利用しない。番号が欠けた窓、再読み込みをまたぐ窓、0.02 ms を超える収支誤差は棄却する。

各パックの中央値・p95 は、同じ場面の A、B 全受理フレームをまとめた値。差分は各組での「新しい版 − 古い版」を求めた。Δ平均は A と B に等しい重みを与えた値で、プールした百分位の差とは異なる。平均時間の内訳には親子の重複がないフレーム直下の区間を使用した。各組の p95 差、実行フレーム数、呼出数、排他時間も集計に収めた。[全窓の数値](summary.json)

## 実行と場面の確認

シード 308060、AqualumenNaturalV2 の私有コピーで実行した。室内は同じ位置・向き、同じ牛 1 頭。夜は白い部屋に屋根とランタン 2 個、正午は屋根を開けて両方を消す。白樺林では時刻 9800、位置 (208.5, 64, 355.5)、yaw 12.7°、pitch −2° を固定し、(207, 64, 359) の空気セルに通常の松明を 1 本置き、最後に空気に戻した。

白樺林の 49 セルのブロック・規定状態と予約した空気 5 セルを照合した。撮影時にも位置・向き・時刻・ブロック・16 チャンクの読み込みを検査した。捕捉格子の原点 (176, 32, 320) から 64³ = 262,144 セルを保存データで読み、溶岩・未読セルはともに 0。松明の復元を全 4 回のログで確認した。旧記録とは基本画角 70°、描画距離 12、解像度が一致する。旧記録と今回の白樺林はスペクテイター、FOV 効果 1.0。飛行による視野拡大をそろえた。室内は静止したクリエイティブ。室内も旧版組では FOV 効果 1.0、p7 / p8 組では 0.0 のため、旧版組は広い範囲を映す。1.8.0 の旧版組の画像を中央で 1.136 倍に切り出すと、同版で FOV 効果 0.0 だった最初の画像との相関は夜・正午とも 3 領域すべてで 0.999 以上。表示範囲は各 ABBA 内でそろっており、p7 参考列との世代間差を同一投影での差とみなすことはできない。旧記録の FPS 上限は 260、今回は 120 で視点揺れはオフ。旧記録の FPS と直接差し引いていない。[白樺林の旧記録](../2026-11-21-lava-light/wall-v190/birch-stable/capture/ground-noon.json)
