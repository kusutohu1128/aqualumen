# 葉が返した松明の光を、森で確かめる

オークの幹に松明が隠れていても、その上にある葉には光が届く。葉が受け取った光の一部を地面に返す試作を、実際に表示された草地の画素で比較した。さらに、葉と不透明面の出射光を計算する順序を変えて、反射を保ったまま負荷を下げた。[前回の反射光の読み取りと仕組み](../2026-11-23-canopy-return/README.md)

## 描画方式

プレビュー10を基準とし、葉の表面色・被覆率・向きから反射光を求める初版と、同じ計算を8×8の同じ向きの面にまとめた版を比べる。後者では、葉の面ごとに中心の一点、通常のブロックには面ごとに四点を使い、同じ光源評価関数を通す。葉への照明、光源までの遮蔽、96本の半球サンプル、二次反射は初版と同じ。実際にメッシュとして現れた葉の面が対象で、葉の内部の体積多重散乱は近似する。[出射光の実装](../../release/leaf-return/shaders/shadowcomp2.csh)・[葉から受光点まで](../../release/leaf-return/shaders/lib/trace_diffuse_face.glsl)

## 実際の表示画素の比較方法

森の隔離コピーで昼夜と天候の進行を止め、保存時のゲーム内時刻68,853（1日の時刻20,853）、露出11.25倍、シェーダー内のアニメーション時刻60秒で撮影した。木のツルハシ・斧・シャベルに計測専用のIDを割り当て、その場で三つの描画方式を往復した。三つとも光を出さず、手とHUDを隠してF2で保存した。画面隅8×4画素の識別印で、切り替わった描画方式を検証した。画面には通常のトーンマッピング・グレア・アンチエイリアスを適用している。[切替パック](packs.py)・[撮影手順](display_walk.py)・[集計](display_results.py)

## 表示結果

暖色点灯・消灯・魂の松明のそれぞれで、地面の同じワールド座標に再投影した。暖色点灯時とその一本を撤去したときの版間差を座標ごとに差し引くと、幹の裏703点では中央値で **+3.07階調**、脇81点では **+1.43階調**。魂の松明ではそれぞれ **+2.15** と **+0.93**。ここでの階調は最終RGBに輝度係数を掛けた0〜255の表示値で、物理的な光量の単位とは異なる。木陰では葉から来る光で草の緑がわずかに明るくなり、幹が作る影の輪郭は残った。[倍率を変えずに切り出した実画面](forest-display.png)・[24枚のハッシュと分布](display.json)

識別印を除く全1,439,968画素を調べると、暖色点灯時の足元視点で19.8%、森を見渡した視点で15.3%の画素で、葉の反射の有無による差が2階調以上あった。両視点で、計算順を変えた版と初版の表示輝度差の絶対値は99%点で0。単一RGBチャンネルの最大差は足元で1階調、森を見渡した視点で2階調だった。比較は静止した画面で、自動露出を含む移動中の知覚や、密林での負荷は別に確かめる必要がある。[撮影時の元Lab・セーブ照合](../2026-11-21-animal-light/woodland/oak-tiles-frozen/complete.json)

Devin経由のClaude Fable 5.2は任意プレビューに賛成し、次は雨夜の密林を松明を持って歩き、濡れた草へ返る光がちらつかないかを確認するよう提案した。計測場面は白樺林に松明4本を置いたもの。[アドバイザーの回答](advisor.txt)

葉の出射色は理想拡散面として評価し、葉ブロック内で直進する光には距離に応じた指数減衰を使う。散乱への配分と減衰係数はAqualumenの近似で、特定の樹種を実測して得た値ではない。基本式の出典は Pharr, Jakob, Humphreys『Physically Based Rendering』第4版。[Diffuse Reflection](https://pbr-book.org/4ed/Reflection_Models/Diffuse_Reflection)・[Transmittance](https://pbr-book.org/4ed/Volume_Scattering/Transmittance)

## オークの柱から湖畔へ

通常のプレビュー10で前回のサバイバルセーブを再開し、オークの柱から水辺に下りて暖色のランタンを置いた。岸に沿って歩き、二つ目の地点で砂を一ブロック掘り、できたくぼみの横に魂のランタンを設置した。保存後のブロック記録で、元の水源は水位0、くぼみに入った流水は水位1だった。両方のランタンと出発地点の柱も残っている。[道中の実画面](shore-journey.jpg)・[流水の保存値](water-entry.json)・[持ち物と保存ブロック](../2026-11-21-animal-light/woodland/lakeside-lanterns/save.json)・[再開用セーブ](../../dist/Aqualumen-Lakeside-Lanterns.zip)

この区間は47.11 m、2,992ティック。継続した3シードの合計は54,108ティック（2.2545ゲーム日）、539.97 m。時刻固定の表示比較とGPU計測は含めていない。[プレイ履歴](playtime.json)

## 計算結果と配布用ZIP

固定した入力で、以前の葉の反射と新しい計算順を、同じGPU上で別々に実行した。暖色の一灯、暖色と青の二灯、ドアと溶岩を加えた場面、光源を外した場面、葉を取った場面を用いた。各場面の出射光と溶岩のテクスチャ全6,291,456個の半精度成分が、RTX・Mesaそれぞれでビット一致した。溶岩を置いた場面では42面への面光源の寄与を読み取り、消灯時は光る葉も不透明面も0になった。Mesaで配布内容の描画プログラムとコンピュートシェーダーのコンパイル・リンクも通った。[RTX](field-nvidia.log)・[Mesa llvmpipe](field-mesa-verified.log)・[ネイティブの検査](field_probe.cpp)・[コンパイル記録](compile-mesa.log)

プレビュー11を `python3 tools/build.py --leaf-return-preview` で再現できる。配布ZIPとGPU計測用試作は139エントリすべての展開後のバイトが一致する。プレビュー10から変わるシェーダーは5ファイル。時刻の固定、道具による切り替え、画面の識別印は比較用パックだけに入っている。プレビュー10と通常版1.8.0も再ビルドし、既存の配布ZIPとバイト一致を確認した。[配布用ZIP](../../dist/Aqualumen-1.9.0-preview.11.zip)・[パッケージの照合](package-check.json)

配布用ZIPと同一のアーカイブを使い、GPUタイムスタンプを外したゲームの描画フレーム間隔を計測した。1440p・12チャンク・松明4本の白樺林で平均73.32 ms（約13.6 fps）、p99は75.90 ms。砂州では平均57.40 ms（約17.4 fps）、p99は62.28 ms。各場面一回の連続区間、VirtualGLの隔離環境での値である。[137・175フレームの測定](../2026-11-23-torch-density/gp-density-leaf-tiles-player/summary.json)

## 雨の夜に樹冠の下を歩く

配布用のプレビュー11を隔離したMinecraftに読み込み、真夜中・雨のオーク林を同じ位置から歩いた。手には暖色の松明、魂の松明、最後に何も持たず、それぞれ約5 m進んだ。出発地点には設置済みの松明がある。三回とも幹の近くを通り、暖色では橙色の樹皮が、魂の松明では青緑色の樹皮と草が写った。手ぶらでは幹の奥の地面が暗い。通常の露出とアニメーションを使った。[3条件の実画面](rainy-oak.jpg)・[暖色の松明の動画](../2026-11-21-animal-light/woodland/rainy-oak-walk-r2/warm-crossing.mp4)・[魂の松明の動画](../2026-11-21-animal-light/woodland/rainy-oak-walk-r2/soul-crossing.mp4)・[手ぶらの動画](../2026-11-21-animal-light/woodland/rainy-oak-walk-r2/empty-crossing.mp4)

別の走行ではF3座標入りの可逆圧縮動画を取り、撮影した141フレームすべてで座標を読めた。照明格子の境界 x=568 を通る前後で、同じ草の表面130地点に投影して表示輝度の中央値を追った。暖色の手持ち松明では約0.22 m進む間に75.44から81.40へ、手ぶらでは34.71から45.63へ変化した（0〜255）。境界の両側から直線を当てて推定した段差は、集計半径0.6〜1.0 mで暖色が−1.9〜−1.1、手ぶらが+10.5〜+15.2階調だった。手ぶらでも大きい変化があり、照明格子・露出・視点補間・幹に沿った影のうち、どれが寄与したかはこの二走行だけでは特定できない。次の切り分けには、設置灯と幹を維持したまま、露出固定と通常露出で同じ区間を往復する比較が使える。[座標とフレームごとの集計](storm-motion.json)・[測定方法](storm_results.py)・[通常走行の保存記録](../2026-11-21-animal-light/woodland/rainy-oak-walk-r2/complete.json)・[座標付き走行の保存記録](../2026-11-21-animal-light/woodland/rainy-oak-tracked-r2/complete.json)

最初の二走行では折り返し後のカメラ旋回が一度で目標角に届かず、二条件目の開始前に打ち切った。その記録を保持し、マウスの入力後にF3で向きを再確認してから撮影するように改めた。上記の数値には両方の通し走行が成功した再試行を使った。天候・時刻を固定したコピーは継続サバイバルの日数集計から除外した。

## Nsight Systemsで捉えた実ゲームの描画待ち

Nsight Systems 2026.5.2で、プレビュー11を読み込んだMinecraft 1.21.1のJavaプロセスを収録した。上の雨夜のオーク林を保存したコピーからもう一つ隔離インスタンスを作り、シェーダーのコンパイルとワールド入場が完了してから収録を開始した。RTX 3080 Ti、専用のCage・Xwayland仮想画面、実ウィンドウ1280×720、12チャンク、カメラ静止。結果をSQLiteに書き出し、Javaプロセスと描画スレッドのIDで集計した。元のLab設定・Modとコピー元セーブのハッシュ照合、ゲーム終了時のワールド保存を確認した。[集計とプロセス情報](nsight-minecraft.json)・[Nsightで開ける収録ファイル](../../build/leaf-tiles/nsight-minecraft-cage/minecraft.nsys-rep)・[SQLite](../../build/leaf-tiles/nsight-minecraft-cage/minecraft.sqlite)

6.043秒間に描画スレッドでOpenGL呼び出し36,651件を取得した。うち画面バッファを交換する `glXSwapBuffers` は166回、CPUがこの関数内で過ごした時間は合計4,718.9 ms、平均28.43 ms、最長30.75 msだった。`glDispatchCompute` は1,837回。1 ms以上のOSランタイム呼び出しも収録しており、このスレッドでは `futex` 2回、`ioctl` 3回が記録された。交換関数がGPU・ドライバ・仮想画面のどこを待ったかは、この記録単独では特定できない。1440pでの画質・速度の比較には、上記の専用プロファイラとフレーム間隔の測定を使う。[収録スクリプト](nsight_rain.py)・[集計スクリプト](nsight_summary.py)

普段のVirtualGLとNsightを同時に差し込むと、MinecraftのX11関数の読み込みが衝突した。VirtualGLを介さずRTXに接続する専用画面を用いた。Cageと不足ライブラリは検証用ディレクトリに展開した。Xwaylandでの初回はシェーダーのリンク中に100秒の起動待ちを使い切ったため、取得済みのドライバキャッシュを引き継ぎ、収録開始条件を満たすまで待った。[実行ログ](../../build/leaf-tiles/nsight-minecraft-cage/capture.log)
