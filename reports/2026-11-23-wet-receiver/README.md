# 雨に濡れた床の松明と、湖畔から岩陰への道

プレビュー13には、手持ち松明の滑らかな半影と、画面に残る地形に松明の光を計算する方式を採用した。プレビュー12から変わるのは4ファイル。白樺林に4本の松明を設置した試験では、手持ち灯の半影を同じ条件にそろえたとき、RTX 3080 Ti・1440p・12チャンクでフレーム間隔が79.73 msから66.76 msに縮んだ。暖色と青の灯りを横切る牛、松明を支える土を採掘する場面は以前の実機試験から引き継いだ。[ビルドしたZIP](../../dist/Aqualumen-1.9.0-preview.13.zip)・[白樺林と採掘の試験](../2026-11-23-visible-terrain/README.md)

## 濡れた床では、どの差が画面に残るか

Minecraft 1.21.1・Iris 1.8.8で夜の部屋の屋根を開け、丸石の床を雨にさらした。暖色のランタンと魂のランタンの間に葉と牛を入れ、最後に両方を取り除いた。いずれも専用の検証ワールドで、撮影の前後に視点・雨・床材・灯り・遮蔽物をサーバー側で確認した。通常描画を1600×900で撮影し、同じ配置で浮動小数点の診断パックも動かした。[室内の配置](paired/geometry.json)・[実画面と差の出た場所](wet-floor.jpg)

通常描画では各段階でF2とX11の計3枚を撮った。雨粒や水はねが通るため、別々の起動で同じ画素を比較すると、葉と牛がいる段階のF2画像ではRGB差の99%点が65階調になった。一方、両方式それぞれの3枚でRGBの変動が1階調以内だった濡れた床の72,766地点では、両方式の取り得た色の範囲の隔たりは最大1階調だった。最初の段階は床が濡れていく途中で、この安定条件を満たした地点がなかった。[通常画像の集計](normal-images.json)

同じフレーム内では、従来の前方描画が計算した局所光を浮動小数点テクスチャに保持し、同じ画素の地形に最終深度から計算した値を比べた。さらに不透明面のRGBに各方式の局所光を入れ、実際のそのフレームの露出と表示曲線・ガンマで8ビット値に換算した。この換算位置より後で大気、雨粒、グレア、輪郭の平滑化が合成される。葉と牛がいるときのF2では濡れた床97,643地点、このうち丸めた表示値に1階調差があったのは4,519地点。3段階・各3枚の濡れた床すべてで2階調以上の地点は0。線形RGBの差の最大は0.02389で、ピークは暖色ランタンのすぐ手前、画像左端付近だった。採用したプレビュー13の全139エントリは、この前後比較に使った最前面方式の通常パックと展開後のバイトが一致する。[同一画素の数値](same-frame.json)・[計器の実装](paired.py)・[配布物の照合](release.json)

濡れた上面向けに、水膜の被覆率と粗さを浮動小数点のまま送る符号化も試した。前後の精度を同じ地形画素で同時に評価すると、今回記録した対数符号化済みのHDR差と整数表示差は同じだった。プレビュー13には従来の格納方法を採用した。Claude Fable 5.2 Highからは、二つの計算法で一致しても水膜モデル自体の正しさは決まらないこと、次は雨の夜に手持ち松明で水辺から洞窟入口へ歩き、動きながらの照明を確認することを提案された。[試作の符号化](packing.py)・[アドバイザーの回答](advisor.txt)

再ビルドは `python3 tools/build.py --visible-terrain-preview`。元のLabの選択はAqualumen 1.8.0・Physics 0.2.0。再現ビルドでプレビュー12と通常版のZIPも既存配布物との一致を確認した。[再現チェック](release.py)

## 雨の夜に湖畔から石の張り出しへ

前回の湖畔セーブを複製し、複製だけ雨の真夜中に固定した。水膜の符号化を試す通常描画パックで、手に松明を持って砂州の二つの灯りを離れ、草の斜面を登り、初めて訪れる岩陰に魂のランタンを置いた。統計に記録された歩行距離は80.57 m。入口の直線区間の最初には頭上に遮蔽物がなく、歩くにつれて屋根は頭上6ブロックから2ブロックまで下がる。カメラの向きを東・下16度に保ったまま6.04 m進んだ。終了後にセーブを読み、ランタン・床・天井がそれぞれ魂のランタン・石・石であることを確かめた。湖畔の松明の下の土には草が生えていた。[雨の行程の実画面](rain-walk.jpg)・[入口を歩く4秒](under-stone-rain.mp4)・[実ゲームの操作記録](../2026-11-21-animal-light/woodland/lake-to-wet-stone/complete.json)

可逆動画を半分の解像度で読み、静止したHUDと右手を避けて、前後両方の画面で追跡できる地形の模様を探した。カメラの進行方向と辻褄が合い、5×5画素の模様が保たれた箇所について、中間の1コマの明るさが両隣の移動量で補間した値からどれだけ外れたかを測った。雨の4秒には119コマ、異なる画面は92枚。動きが十分大きい35組で3,832個の比較が成立し、ずれの中央値は0.31階調、95%点1.29、99%点2.41、最大10.51だった。最大の3コマでは草の縁に雨筋が重なり、中心付近が一瞬明るくなった。追跡できた模様と雨粒を含む表示輝度の観測で、個々の光源のちらつき量を直接測ったものではない。[最大の3コマ](lake-to-wet-stone-tracked.jpg)・[追跡の範囲と数値](lake-to-wet-stone-motion.json)・[照合方法](motion.py)

## プレビュー13で岩陰に灯りを残す

同じ湖畔のセーブから、天候と時刻が自然に進むサバイバルで配布版を起動した。昼間に89.89 m歩き、最後の魂のランタンを岩棚に置いた。湖畔の松明・魂のランタンと新しいランタンが保存されたことを終了後のチャンクで照合した。今回の5,218ティックを加え、通常プレイの累計は3シードで82,109ティック（3.42121ゲーム日）、923.43 m。雨夜の複製はこの累計から除いた。[4場面の実画面](survival-walk.jpg)・[終了後のセーブZIP](../../dist/Aqualumen-Stone-Camp.zip)・[設置物の座標と時刻](../2026-11-21-animal-light/woodland/lake-to-stone-camp/save.json)・[累計の内訳](playtime.json)

岩陰で魂のランタンを置き、視点を固定したまま松明を手に持った。ランタンの右側にある同じ石の90×54画素で、昼の配布版の表示RGB中央値は (42, 81, 98) から (126, 113, 105) に変わった。雨の真夜中の試作では (43, 94, 113) から (147, 131, 121) に変わった。どちらも右側の石の赤成分が上がり、足元のランタン自体は青く残っている。数値は露出と表示処理を通ったF2画面の値。[昼の画素と画像ハッシュ](survival-lantern.json)・[雨の夜の画素](rain-lantern.json)

通常の昼の入口でも4秒に119コマを収録し、6.04 mの移動で異なる56画面を得た。22組の3コマで追えた地形の模様1,308件の輝度ずれは中央値0.24、99%点1.97、最大5.10階調。最大点は石と暗い段差の境にあった。天候・時刻・パックが異なるため、雨の動画との数値差からパック間の優劣は判定できない。[昼の最大点の3コマ](lake-to-stone-camp-tracked.jpg)・[全体の集計](lake-to-stone-camp-motion.json)

## 丸石の水平面を照明がどう受け取るか

水膜を高精度で渡す試作には、法線がちょうど真上を向く場合にだけ使う経路がある。実際にその経路を通ったかを、最前面の地形を照らすパスの中で調べた。二つの視線方向、雨・葉・牛を変えた3段階の合計9枚で、濡れた水平な床を延べ1,002,634地点読み取った。元の三角形の法線の水平成分は各軸とも絶対値0.000214以下だったが、シェーダーが受け取った頂点法線は全地点でマイナスZ方向に約0.45度傾き、格納後は約0.47度になった。高精度に切り替わった画素はこの範囲で0。以前の同一フレームで精度を変えても結果が一致した理由は、この床では両方とも同じ形式を使っていたためだった。[照明パス内の法線](normals.json)・[二つのカメラの位置](normals-at-two-angles/geometry.json)・[GPUの計器](normals.py)

使用中のIris 1.8.8の地形頂点では、法線の向きを八面体座標に変換し、各成分を127倍して整数部を格納する。真上を符号化した (0.5, 1) が (63, 127) になる計算を逆にたどると、Z成分は約 −0.0079363。GPUの読み出し刻み1/32768で丸めると実測の −0.00793457 と一致する。中間テクスチャを読み直す前からこの差がある。

## 水膜がある水平面の補正版

プレビュー13の局所光を、試験室に設置した丸石の床だけで正確な上向き法線を使って計算し直した。葉と牛のあるF2では、同じ露出で調べた528,498画素のうち26,269画素で表示が2階調以上変わった。鏡面反射の成分だけを置き換えても24,867画素が2階調以上変化し、最大4階調。床の局所光全体では1画素で7階調になった。葉と牛を除いた視点では、変化が集中するのは暖色灯の映り込みの縁だった。[測定位置](flat-stone.jpg)・[実測値](flat-stone.json)・[同じフレームでの比較方法](flat_lamp.py)

補正版は、水膜ができ、画面上の三角形がほぼ水平（水平成分の傾き0.0005以下）で、頂点法線がIrisの真上の符号値に合うときだけ、面の向きを上に戻す。斜面と切り抜きの判定が乱れないよう、三角形の向きはアルファテストの前に求める。修正後の同じ試験室では、二つの視線方向で得た9枚・延べ4,002,698画素すべてが上向きになり、水平面を指定して再計算した局所光との表示差は0階調だった。これは大気や雨粒を合成する前の照明についての照合である。Mesaでも配布用パックの全プログラムをコンパイルし、実装から取り出した水膜処理に実際の三角形の微分を与えて10条件を確認した。傾斜した面、水膜がつながっていない面、別の頂点法線、乾燥、雨を遮った面などの対照はプレビュー13と同じ出力だった。[補正後の実画面](corrected-stone-release/wet-leaf-cow-ingame.png)・[補正前後のOpenGL対照](plane-controls.json)・[コンパイル記録](compile-wet-plane-mesa.log)

[水膜の補正版ZIP](../../dist/Aqualumen-Wet-Plane-Study.zip) は `python3 tools/build.py --wet-plane-study` で再現できる。プレビュー13から変わるのは地形のフラグメント処理と水膜の処理の2ファイル。最初の参照計器はGLSLの予約語の使用で起動できず、名前を修正して別ディレクトリで再収録した。補正後の通常描画の最初の撮影は、私が同時に起動したMesaのコンパイル検査を監視が検出して打ち切った。その撮影を除外し、配布用ZIPを単独で起動して3段階すべてを記録し直した。[除外した記録](corrected-stone-ordinary/preflight.json)・[配布用ZIPでの完了記録](corrected-stone-release/complete.json)

## 岩陰で松明を持ち替えて歩く

アドバイザーの指摘を受け、通常プレイでランタンを置いた岩棚のセーブを二つ複製し、両方を同じ雨の真夜中にした。配布用プレビュー13と水膜補正版をそれぞれ実Minecraftで起動。岩棚から雨の落ちる草地まで出て、立ち止まったまま松明を右手→左手→右手に替え、同じ方向を向いて再び岩の下へ歩いた。ゲーム内の入力で持ち替えると、草の段差の脇のくぼみに影が移った。水膜補正版の同じ22×22画素の表示RGB中央値は (103, 75, 50) → (30, 24, 19) → (102, 74, 49)。青いランタンは奥で点灯し続けた。プレビュー13でも同じ変化を確認し、終了後に両セーブの灯り・手持ち品・設定を照合した。[松明を持ち替えた6場面](camp-hand-light.jpg)・[元セーブと観測値](camp-comparison.json)

4秒ずつの実画面で、入口の移動はプレビュー13が6.26 m、補正版が6.04 m。両方とも120コマを取得し、別画像は98枚と99枚。39組の3コマで追えた模様は6,435件と6,720件、輝度のずれの99%点は3.20階調と3.19階調。最大は16.53階調と23.80階調で、どちらの最大点も接近していく草ブロックの上面と側面の境界に重なった。異なる雨粒とわずかに異なる移動量を含むため、最大値の差だけでは水膜によるちらつきかどうかは判別できない。先の湖畔からの試走（99%点2.41）は岩棚にランタンを置く前の別の照明条件だった。[補正前後の同時再生](camp-crossings.mp4)・[プレビュー13の最大点](camp-rain-reference-tracked.jpg)・[補正版の最大点](camp-rain-wet-plane-tracked.jpg)

## 雨を切り替えた瞬間の実画面

同じ二灯・丸石・屋根なし・真夜中の部屋で視点を固定し、サーバーから降雨と停止を指示した。それぞれの前後で床・灯り・視点と天候フラグを照合し、通常描画の左下480×200画素を毎秒30コマで11秒ずつ可逆収録した。処理前の計器と異なり、大気・露出・雨筋・表示曲線を通った画面を読んでいる。通常サバイバルのセーブと天候はこの操作の対象外である。[乾いた床・降雨中・停止後の実画面](weather-cycle.jpg)・[天候切り替えと撮影条件](weather_cycle.py)

暖色ランタンの映り込みにかかる固定64×64画素で、各コマのRGB中央値を表示輝度に換算した。330コマ中、隣のコマとの最大段差は降り始めが両方式とも1.00階調。停止前後ではプレビュー13が2.01階調、補正版が2.08階調で、いずれの最大点も雨を止めるコマより前にあった。降り始めの直前から約5秒後までのRGB中央値は両方式で (172, 143, 117) → (169, 140, 115)。その後の通常写真で、暖色灯の映り込みは時間をかけて明るくなり、雨が止んだ後にも残った。これはこの小領域の値であり、全画面の各画素の段差や完全に乾くまでの時間には外挿しない。[全4収録の時系列集計](weather-cycle.json)・[フレームの読み取り](weather_result.py)
