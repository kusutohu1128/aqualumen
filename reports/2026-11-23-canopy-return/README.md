# オークの葉から林床へ返る松明の光

オークの幹が落とす影の中で、松明の光が葉に一度当たってから草に届くかを調べた。プレビュー10は木や土などの不透明面から返る局所光を二回の反射まで扱う。葉を通る反射光には距離に応じて減衰をかける。ここでは実際に描かれた葉の表面が、松明に照らされたときに返す光を加える試作を比較する。[前の観測とアドバイザーの所見](../2026-11-23-oak-shadow/README.md)

## 条件

実Minecraft、RTX 3080 Ti、1600×900、12チャンク。シード308060の保存地点からそれぞれ隔離コピーを起動し、幹を残したまま同じ草地に立った。座標 (566, 64, 419) の松明を暖色、撤去、魂の松明、暖色の再設置の順で撮影した。周囲にも元から光源がある。松明を撤去した状態が、この一本で加わる光を測る基準になる。[保存地点と所持品](../2026-11-21-animal-light/woodland/oak-night-trail/save.json)・[操作](forest_meter.py)

観測帯は深度と面の向きで上向きの草地を特定し、同じワールド座標で一次・二次反射のRGB、草の反射色、全局所光の輝度、HDR色、露出を読む。F2画像には浮動小数点の上位24ビットを格納した。各状態を二回撮影し、両版・全状態で草地が見え、反射光の重みが最大だった点を比較する。ゲーム内時刻と環境光は撮影中も進む。表示差の推定には、現行版の同じ画素と露出を使い、反射光の差分だけを加えてトーンマッピングする。近隣画素によるアンチエイリアスとグレアはこの推定の対象外。[GPUでの読み取り](meter.glsl)・[集計](read_meter.py)

## 実装と検証履歴

試作は既存のテクスチャに、実際の葉の面の向きとバイオーム色、アトラスから得た葉の色と被覆率を用いて局所光による反射を格納する。草地からたどる既存の96本の光線がその面を横切ると、葉で減衰した分の一部が反射光として寄与する。葉の奥にある不透明面への経路も継続する。追加のテクスチャ割り当てはない。[面の記録](leaf_capture.glsl)・[反射の計算](leaf_exit.glsl)・[光線が葉を通る処理](leaf_segment.glsl)

初回の試作はNVIDIAのコンパイル時に、浮動小数点テクスチャから整数への暗黙変換で停止した。整数変換を明示して新しいファイル名で再作成した。初回のログは保存している。[初回のログ](../2026-11-21-animal-light/woodland/oak-return-leaf/client.log)

## 森の実機結果

暖色点灯時は現行版で32地点すべてを読めた。光源を抜いた状態も含めた全16枚を照合し、幹の裏10点、脇13点が共通の判定を満たした。下表は「対象の松明あり − 同じ版でその一本を撤去」を点ごとに求め、さらに「試作 − 現行」をとった差の中央値。線形輝度はシェーダー内部の相対値。[全16枚のハッシュと地点別データ](meter-results.json)・[現行の完了記録](../2026-11-21-animal-light/woodland/oak-return-stock/complete.json)・[試作の完了記録](../2026-11-21-animal-light/woodland/oak-return-leaf-r2/complete.json)

| 草地 | 暖色の一次・二次反射の合計差 | 暖色の全局所光の差 | 暖色の表示差の推定（255階調換算） | 魂の松明の表示差の推定 | 暖色を戻した後の表示差の推定 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 幹の裏（10点） | +0.0002932 | +0.0002935 | +3.56 | +2.47 | +3.45 |
| 幹の脇（13点） | +0.0005307 | +0.0005457 | +1.11 | +1.08 | +1.12 |

幹の裏では、試作の重複撮影で反射光の差は最大0.0000049だった。暖色光を当てると葉から返る光は緑成分が最も大きく、魂の松明に換えると青成分が赤成分を上回った。木陰の位置と、松明を抜いたときの対照がそろうことで、夜明けの露出変化と混同せずに反射の増加を追えた。3.56階調は同じHDR画素に対する推定であり、プレイ中に違いを見分けられるかは別の評価になる。両走行は元のLab・MOD・保存元の照合に通り、隔離コピーは正常終了した。診断で歩いた距離と経過日はサバイバルの継続記録に加算していない。

Devin CLI経由でClaude Fable 5.2に測定値を示した。Fableは、木の影から選んだ点での表示推定が、森全体で人が違いを知覚できる証拠としては足りないと指摘した。時刻と露出をそろえた表示の比較と、同じGPU時間をほかの描画処理に使った場合との比較を提案している。[助言の原文](advisor-followup.txt)・[暖色点灯時の実際のF2画像](../2026-11-21-animal-light/woodland/oak-return-leaf-r2/warm-a-ingame.png)

## GPU時間と採用判断

実Minecraft・RTX 3080 Ti・2560×1440・12チャンクの白樺林、松明4本。画面の数値表示を外した試作をパック専用GPUプロファイラで測り、同じ場面・同じ計測手順の保存済みプレビュー10と比較した。[現行版の151フレーム](../2026-11-23-oak-shadow/gp-density-oak-stock-b/summary.json)・[試作の133フレーム](../2026-11-23-torch-density/gp-density-canopy-return-r2/summary.json)・[元LabとGPUの使用状況の照合](../2026-11-23-torch-density/gp-density-canopy-return-r2/preflight.json)

| 平均時間 | プレビュー10 | 葉の反射を加えた試作 |
| --- | ---: | ---: |
| GPUフレーム全体 | 61.15 ms | 69.88 ms |
| 面から出る光を計算するパス（shadowcomp2） | 2.47 ms | 10.87 ms |
| 一次反射を集めるパス（shadowcomp3） | 2.26 ms | 2.87 ms |
| ゲームの描画フレーム間隔（プロファイラ有効） | 66.47 ms | 75.33 ms |

GPUの増加8.73 msに対し、葉面を含めて出射光を求める処理の増加が8.40 msだった。計測は各版一つの連続区間。木陰に戻る光の増加は測れたが、現段階では試作を配布版に採用しない。次の候補は、同じ時刻・露出で見たときにどの葉の寄与が見えるかを確認し、寄与の小さい葉面を安く処理できるかをこのパスで調べること。
