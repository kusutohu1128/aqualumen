# 水中の細かい歪み：波の描画帯域の診断

2026-10-03 JST。**診断用・通常版未採用。水と太陽光の最終目標は未達。**

同じ水面形状のまま、水中の既知の上面だけ、光学用の波の細かさを
detail1からdetail0へ変更したTESTパックを比較した。通常シェーダーと
配布版0.8.6は変更していない。

## 結果

- 深い水中では細かい穴・折れ返りが大きく減った。浅い位置と斜めの
  視点では形も変わり、縁のうねりは残る。全体の見た目の合格ではない。
- 水中7点で、実際の波の高さから計算した傾きとの整合性テストに合格。
  局所的・限定条件での確認であり、すべての水面での保証ではない。
- ネイティブ検証v2は**全体として不合格**。水上側の厳密な値一致に
  最大約1.19e-7の差が残る。微小でも後から合格基準を変更していない。
- 暗い外周は残った。選択した観測点では反射先が見つからない判定も
  変わらず、波の細かさだけでは解決しない。
- 6画面・計3,552フレームの記録とGPU読み戻しを検証済み。
  1600x900・上限120FPSの静止比較であり、最低FPSの保証ではない。

細かい波の分布を分け、反射・屈折への影響を各方向で評価するもの。

エネルギーと相反性の検証が残る。

[一時停止画面](ordinary-restored-paused.png)を確認。

自動変更は行っていない。[環境の確認記録](HANDOFF.json)を参照。
