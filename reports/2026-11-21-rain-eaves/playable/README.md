# Aqualumen Rain Walk（雨の散歩道・遊べるサバイバル・ワールド）

Minecraft Java 1.21.1 用の、新規・単独のサバイバル・シングルプレイ・セーブ（ピースフル）。通常の Aqualumen（Iris 1.8.8 /
Sodium / physics）で遊ぶためのもの。既存のセーブ・Lab インスタンス・Lantern House は一切使っていません。

- 配布物: `dist/Aqualumen-Rain-Walk.zip`（最上位フォルダ `Aqualumen-Rain-Walk/` に `level.dat` と `region/*.mca` のみ。約 34 KB）
- 生成: `python3 -I build_world.py <dir>` → `python3 -I package.py <dir>/Aqualumen-Rain-Walk <zip>`（標準ライブラリのみ、決定的。
  `build.sh <scratch> <zip>` が生成→梱包→検証をまとめて実行。3 回のビルドで SHA-256 が一致）
- 検証: `python3 -I validate_world.py <zip> --json validation.json --map map.txt`（`build_world.py` を import しない、独立した
  NBT/Anvil デコーダでパッケージ済みチャンクを読み直す）。`map.txt` は上から見た図とルート断面。
- ネイティブ煙テスト: `smoke.py`（使い捨てコピー、レンダーロック下、WASD の S/W のみ）。結果は `smoke-rc3/`。

## 設定（level.dat、実際に読み直して確認済み）
- サバイバル（GameType 0）、難易度ピースフル、チート無効、ハードコア無効。ゲームルールは空（＝すべて既定値なので昼夜サイクル・
  天候サイクル・mob 設定は通常どおり）。データパック / コマンドブロック / ファンクション / テスト用 MOD / マーカーファイル /
  プレイヤー UUID はなし。スーパーフラット（プレーンズ）、構造物・フィーチャー無効、固定シード。
- 開始時刻 `DayTime = 10000`（夕方 16 時）、`raining = true`、`rainTime = 3600`（180 秒）、`clearWeatherTime = 0`、雷なし。
  3600 tick 後に vanilla の天候サイクルが雨を止め、以降は自然に進行します。雨の止まる時刻は DayTime 13600（日没後）。
  **注意:** Iris のパイプライン構築（コールドキャッシュで約 100 秒）の間もサーバーは進むため、最初のフレームが出る時点で
  雨は 70〜80 秒ほど残っています（暖かいシェーダーキャッシュなら短縮）。
- 初期状態: 地面に立った状態（パッチの石の床の上）、体力・満腹度満タン、飛行不可。ホットバー: スロット 0 は空でそれが
  選択中（手は空）。スロット 1 たいまつ 16、2 ランタン 4、3 ソウルランタン 4、4 鉄のツルハシ。他のアイテムなし。
- 看板は 2 枚だけ（日本語、バニラ）: 出発地点の「北へ まっすぐ / 木 → 坑道 → 池 / (Sキーで もどる)」と、池のほとりの
  「池の ほとり / 南へ もどると / 坑道 と テラス」。

## ルート（局所座標 x=東, z=南, y=上。ワールド座標は x, z が同じ、y は局所 y − 61）
スポーンは (3.5, 12.5)、真北（yaw 180）を向いて木造パティオの開いた側の石の床に立ちます。**ルートは x = 3.5 の一直線**なので、
W を押し続けるだけで全行程を歩け、S で同じ線を戻れます（視点操作・ジャンプ・クリック不要）。全セルが地面と同じ高さ
（段差 0）、頭上 2 ブロック以上。

| 区間 | z（線上） | 内容 |
|---|---|---|
| スポーン | 12.5 | 軒先（パティオ）の開いた側。ランタンとその鏡面反射が画面に入る向き |
| 軒下 | 5.9〜0 | 屋根（暗いオークの板）の下。石 / 磨かれた石の床の覆われた側。ランタンは線の右 3 m |
| 戸口 | 0 | 奥壁の戸口（x 2..4） |
| たいまつの木 | −9 | 線の右（x=6）にオーク。幹の西面にかべ掛けたいまつ（x=5）。スポーンからも戸口越しに見える |
| 切り通し→坑道 | −32〜−55 | 低い森の尾根（高さ 9）を貫く、梁付きの木枠のトンネル。長さ 19、空は完全に遮蔽（上に石 3 ブロック以上）。ポータルにたいまつ、中ほどの広間（z −48..−44）にランタン、−50 付近が最も暗い |
| 池 | −80 以北 | 小さな入り江（水深 2、水面 400 セル、西へ細い入り江）、石・丸石・苔むした丸石の岸、サトウキビの群生、スイレン |

全長（スポーンから岸まで）92 m ≒ 約 21 秒（W）。

### パティオ（`fixture/fixture.py` の幾何をそのまま平行移動）
- 屋根 y=5 が z 0..5 を覆い、軒（ドリップ線）は z=6。床は y=0（地面と同じ高さ）。
- 本物の `minecraft:stone`（x 3..5）と `minecraft:smooth_stone`（x 7..9）が、覆われた側（z<6）と露出した側（z≥6）の両方に
  またがる（z 1..14。fixture は 1..11、スポーン用に南へ延長）。
- 吊りランタンは fixture と同じセル (6,4,5) で屋根から下がる。石の対（z 4.5/6.5、2.5/8.5）はランタンから等距離。
- スポーンの目（x 3.5, 高さ 床+1.62, z 12.5）から見たランタンの鏡面反射点は露出した石の上（4.49, 10.19）。視線は遮られない。
  スムース・ストーンへの反射点（pose B 相当）は目 x≈9.49 から（x=8.5, z=10.19）。

## 検証の中身（`validation.json`、すべて通過）
アーカイブ構成と固定タイムスタンプ、level.dat の各項目、ホットバーと選択スロット、禁止ブロックなし、ブロックエンティティは看板 2 つのみ、
ストリップの素材と屋根の下/外の判定（真上の光線）、4 組の等距離ペア、反射点の素材・露出・視線とフレーミング、直線ルートの
連続性（往復）、BFS（段差 0 のみ / ±1 段差）、ルート沿いの水・危険物なし、トンネルの上の石厚と頭上高、トンネル内の光源配置、
たいまつの木、池が 1 つの連結した水（流出なし）、サトウキビの基部が水に接する、葉が永続（腐らない）、尾根に木が 10 本以上。
**日光・空・照明の値は計算も主張もしていません（幾何のみ）。**

## 制限
- 歩行の実測（速度・座標）と 20 分の連続走行はこのレポートの範囲外／親の担当。ここでのネイティブ試験は数分のルート煙テスト
  であり、長時間受け入れ試験ではありません。
- 受動的な動物（羊など）は通常どおりスポーンし得ます。ルートが一時的に塞がれる可能性があります。
- 夜は暗く（たいまつ付き）、雷雨は通常の天候サイクルでいずれ起こり得ます。
