# weather-light: 降水粒子の照明 (STAGING 候補)

`build/weather-light-staging/Aqualumen-weather-air.zip` (sha256 は `status.json`)。rc3 ZIP (`2c814393…`) からの差分は 2 ファイルだけ:
`shaders/gbuffers_weather.fsh` (変更) と `shaders/lib/weather_light.glsl` (新規)。`gbuffers_weather.vsh`、スプライト、被覆 (alpha/discard)、
地形側の画像は変更なし (ハッシュと probe で確認済み)。Minecraft は起動していない。通常 (非計装) 環境での目視比較は root 側。

## 何が変わるか
rc3 は全降水に `vec3(1,.56,.25)*pow(lightmap.x,3)*2` を足していた。`lightmap.x` は雨柱ごとの地上値なので、遠景・ソウル光・遮蔽ランプまで橙になっていた。

- **ランプ**: 粒子ごとの位置で `aqualumenLightList` の実光源を使う。色は地形と同じ `lampColor`。点光源の減衰 `11(level/14)²/(0.38+d²)` と範囲フェザーも地形と同一。
  可視性は `lampVisibility` (ブロック、ドア、色付きガラス、モブ。手持ち光源はホルダー自身を除外)。
  上位 `WEATHER_LIGHT_SOURCES=4` 個だけを追跡する (件数上限あり)。
- **角度**: 正規化 Henyey-Greenstein 混合 (球面積分 = 1)。`mu = dot(視線 eye→粒子, 粒子→光源)`、`mu=+1` が前方散乱。雨は前方ローブが強く、雪はほぼ拡散。`gtexture` の青赤差で滑らかに混合する。
  Lambert の余弦は使わない。
- **太陽**: 同じ位相関数。地形の影 (`shadowVisibility`) と雲/大気の透過に従う。`sun.y` の余弦と二重の `access` 乗算をやめ、水平線だけゲートする。
  空の拡散項は rc3 と同一 (Sun が地平線下なら出力が rc3 と 1e-5 以内で一致)。
- **ローカル光は太陽の可視性・空アクセス・降雨強度のいずれも掛けない** (加算のみ)。
- **未対応光源 / グリッド外**: 中立 (非橙) の弱い環境光 `0.66*0.08*lightmap.x³`。24 m グリッド縁は地形と同じ 19→24 m の smoothstep でフェザー。
- 光度の強さ (`weatherAlbedo=0.66`、環境光 0.08、ソフト上限 16、位相の重み) は**ヒューリスティック**で、物理測定ではない。

## 証拠 (実 NVIDIA GL: RTX 3080 Ti, GL 4.6 NVIDIA 580.173.02)
`weather_light_probe.cpp` は実際の `gbuffers_weather.vsh/.fsh` を本物の光リスト (実 `shadow_*.vsh` + `shadowcomp1.csh`) で動かす。
比較対象 (旧式) は rc3 の無改変 `gbuffers_weather.fsh` を同じ装置で動かしたもの。CPU 参照は C++ double で独立に書き直している。

- `evidence.json` / `probe.log`: **30 チェック全合格**。
  - 位相の正規化と CPU 一致、旧式が自身の式を再現すること。
  - 被覆と discard が rc3 と完全一致。
  - 消灯 / 暖色 / ソウル / 7 種のパレット (CPU 色度誤差 < 0.01)。
  - 石の遮蔽 (遮蔽 0、リスト値 0.5 でも明るさ約 1%)、色付きガラスのチャンネル別透過 (誤差 < 0.5%)、自己発光ブロックの自己影なし。
  - 手持ち光源 (CPU 一致、壁遮蔽、除去、壁に押し付けた場合)。
  - 前方/側面/背面 (雨 7.6 倍、雪 1.9 倍、混合は中間)、距離・14 m 打切り・ランプ擦れ違いのソフト上限。
  - 昼間の太陽 (CPU 一致、地形影と雲影で 0、水平線下で 0)、ローカル項が太陽の影と空アクセスで不変。
  - 未対応光源 (旧 2.0 に対し約 1/25)、グリッド縁と 8 m タイル境界のフェザー (誤差 ~1e-7)、追跡数 ≤ 4 (30 灯でも)。
- `mutation.json`: 12 種の変異 (橙の復活、可視性なし、太陽影の乗算、Lambert、影なし、等方、非正規化、全ランプ暖色、符号反転、範囲なし、被覆変更、追跡数 12) を全て検出。
- `compile-only.log`: パック全 29 プログラムが link (元の glcheck `--compile-only`)。`package.json`: ZIP 差分とハッシュ。

旧式との比較 (ランプから 1/2/4/8/12/16/22 m、列光 0.9): 輝度は旧 0.920 一定 → 新 0.56 / 0.20 / 0.073 / 0.038 / 0.033 / 0.037 / 0.037 (下限は中立環境光)。
ソウルは旧 `(0.69,0.38,0.17)` 橙 → 新 `(0.018,0.072,0.106)` 青。

## 注意 (正直な範囲)
- 昼間の太陽項は余弦を外したので、低い太陽で rc3 より強くなる (probe: 仰角約 17° で 0.10 → 0.23、高い太陽では 0.064 → 0.083)。目視で要確認。
- コスト (GPU ハーネス、合成クアッド 1280x720 全面被覆、Minecraft フレーム時間ではない): rc3 0.023 ms → 灯なし 0.045 / 1 灯 0.33 / 12 灯 (容量) 0.78 ms。
  実際の降雨の被覆率は全面よりずっと小さい。`WEATHER_LIGHT_SOURCES` で調整できる。
- 列ごとの `lightmap.x` は地上値なので、未対応光源の環境光は柱の上まで弱く伸びる (弱い中立光のみ)。
- モブによるホルダー遮蔽は `lampVisibility` を地形と共有している。この probe は空のモブ場で動かすので、モブ三角形は検証していない (`make check-entity` の範囲)。
- GPU ロックは取っていない (サブ秒、約 6 秒/回はほぼシェーダコンパイル)。`take-5` は 05:04:17 に完了済みで、重なっていない。
  写真 QA の `fixture/rc3-r1` とは並走した (許可範囲のはず)。
