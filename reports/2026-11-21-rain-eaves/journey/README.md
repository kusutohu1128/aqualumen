# 森・坑道・池を通る通常プレイの記録

通常のサバイバルで時刻と天気を自然に進め、同じ道を往復する。配布ワールドを使い捨てのゲームディレクトリに展開し、通常の Iris、Sodium、接触波紋 Mod だけを読み込む。ゲームにコマンドを送る処理はない。入力前に、実行時の識別子、プライベートなセーブとプロセスの作業ディレクトリ、フォーカス中のウィンドウの所有者を照合する。

位置は Minecraft の F3 に実際に描画された XYZ と向きから読む。インストール済み 1.21.1 のフォントのビットマップに照らし、目標地点と実座標の差を使って W または S を押す。松明の取り外し・設置は、F3 に表示される樹幹または松明の座標を確かめてから操作する。到達座標、ゲームが保存した歩行距離、時刻、天候、通常終了をそれぞれ記録する。[座標の読み取り](hud.py) · [通常プレイの手順](run.py)

録画は 2560×1440 の Minecraft ウィンドウから取り、閲覧用に 960×540・12コマ毎秒に縮小する。1920×1080 のデスクトップから画面外へはみ出る部分も含めて、対象ウィンドウの X Composite ピクスマップに描かれた色を直接読む。全体の四隅を指定色で塗った独立の通信試験を先に実施した。[画面取得](window.c) · [通信試験の座標と RGB](transport.json)

短時間の先行撮影では、スタートの z=12.5 から池の z=−77.059 への往路を実測できた。最初の復路は負の時間を渡していたため、池のそばで終了した。独立に読み取った各地点の座標を保存した。[先行試験の実座標](short-smoke-positions.json)

実ゲームでは画面外にはみ出たウィンドウの保持ピクスマップから地形は読めたが、F3を切り替えても保持した画像に文字が現れなかった。この方式を用いた2回の起動を記録に残し、実際の画面を直接収録する1600×900のウィンドウに切り替えた。2560×1440のフレーム時間は同版の別の専用測定で取得した。[保持画像の結果](run-5/unreadable-hud.png) · [1440pフレーム時間](../material/take-10/complete.json)

## 木陰で松明を外す

雨の夕方と、同じセッションの晴れた日中に、オークの幹に付いた松明を素手で外し、同じ面に付け直した。各回でゲームが表示した注視ブロックは松明 (5, −59, −9) → 幹 (6, −59, −9) → 松明 (5, −59, −9) と移った。消灯・再設置の位置と視線はそれぞれ一致している。[操作記録](run-7/actions.json) · [カメラとブロックの位置](run-7/positions.json)

| 見た場所 | 雨の夕方　点灯時／消灯時 | 晴れた昼　点灯時／消灯時 |
| --- | ---: | ---: |
| 火の上の樹皮 | 7.33倍 | 4.84倍 |
| 火の横の樹皮 | 6.81倍 | 4.59倍 |
| 樹冠が日陰を作る芝 | 3.39倍 | 2.05倍 |
| 奥に見える別の白樺 | 1.03倍 | 1.00倍 |

同じ長方形の表示色をsRGBから線形に戻した後、輝度の中央値を取った。炎、照準、手、ホットバーを避けた。実際のゲームの露出と、自然に動く天気を含む値である。再設置後の晴天の樹皮は4.84倍、芝は2.01倍に戻った。[表示輝度・画面座標・再設置後の値](run-7/torch-pixels.json) · [晴れているときの松明](run-7/daylight-oak-torch-on.jpg) · [消灯](run-7/daylight-oak-torch-off.jpg)

Opus の目視では、日陰の草が明るくなることと、奥の木が落とす影が残ることを確認できた。一方で幹の橙色が一様に見えると指摘した。カメラから幹の西面に当たる光線を復元すると、上表の二つの樹皮領域は松明から実際には0.83・0.62ブロックの距離にある。炎や煙を避けた幹の側部で距離帯ごとに比べたところ、晴天の点灯／消灯の表示輝度比は、0.29～0.45ブロックで7.68倍、0.65～0.85で4.82倍、1.10～1.35で2.73倍、1.60～2.00で2.18倍だった。この幹のサンプルでは赤が250/255以上になった画素は0%。距離減衰は実際に働いている。光の色の鮮やかさ、墨のように暗く見える煙、複数の灯りを置いた自然林での見え方は引き続き目視で評価する。[Claude Opus の画像レビュー](oak-opus.json) · [実カメラ位置から測った距離別の樹皮](run-7/bark-falloff.json)
