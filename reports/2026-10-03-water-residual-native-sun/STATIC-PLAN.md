The positive cap measure is consistent: delta=2*sin(radius/2)^2 gives
dOmega=delta*dq*dphi, and constant cap radiance beam/(pi*sin(radius)^2)
returns the perpendicular beam. No extra decay/weather/eta factor is needed.

projected slope density, original Fresnel and orientation/reconstruction tests.
The CPU four public tests passed under root execution, as did five public STUB

Two unconditional legacy calls are the proposed later CAP architecture: first
save the full source with WNS_active=false, then compute the base with active
candidate Sun-removal. Evaluate full original environment and base Moon before
selection in both calls. New node rejection returns the saved full result,
without another derivative-bearing legacy call inside a new varying branch.
This avoids introducing that explicit derivative fallback hazard; implicit
receiver lookups remain restricted to the NEAREST/base-level diagnostic.

Legacy WR fields are source-independent in the current source: n/v/covariance,
facet geometry, trace classes, Fresnel and projected coefficients do not depend
on airSky RGB. Verify actual fields/control neutrality anyway; do not infer
compiler byte identity solely from source review. Positive cache affects scatter
and must be removed using actual R times measured scatter difference.

Zero beam is a negative control: requested1/applied0/rejection0, full legacy.
Positive beam requires Earth atmosphere, finite nonnegative source, strict SPD,
qualified raw n/v and every generated node/receiver. Any unsupported or failed
replacement is applied0, full legacy, without partial-node renormalization or an
epsilon inverse. No CAP source is written before native central-response RED.

Known limits remain explicit: central sharp source is not derivative-filtered
pixel equivalence; fixed positive nodes are not a global/singular/critical or
occlusion proof; no Smith/multiscattering or transport-index calibration;

claim. New TEST packs have no world guard and are not shipping/adopted artifacts.
