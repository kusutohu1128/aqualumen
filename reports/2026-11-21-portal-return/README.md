# ポータル往復後も2色のローカルトーチが残るかを実クライアントで確認(Aqualumen 1.8.0)

結論: 私設クライアントで、前哨のトーチ2本(暖色・ソウル)を撮り、点火済みポータルでネザーへ行き、同じポータルから戻って同じ位置で撮り直した。戻った後も2色とも写っており、前後の画像は、炎の動きによる差を除いて同じに見える(帰還位置の差は F3 で (−0.007, 0, −0.017) ブロック)。正式な実走は [`run2`](run2/)。機械可読の記録は [`result.json`](result.json)(run2 の全記録は [`run2/complete.json`](run2/complete.json))。

## 実走の条件
- クライアント: Minecraft 1.21.1 / Fabric / Iris 1.8.8 + 本番jar3本(テストModなし)。シェーダーは `dist/Aqualumen-1.8.0.zip` のコピー(sha256は result.json)。ドライバキャッシュは既存のものを読み取り専用でコピー。
- レンダラー: NVIDIA GeForce RTX 3080 Ti(クライアントログで確認)、VirtualGL egl0 → 私設 Xvfb `:260`、1600×900、maxFps 60。FPS目標なし。F3表示は37〜60だが測定値ではない。
- GPUロック: `/tmp/aql-render21-1000.lock` を SHARED・非ブロッキングでゲーム作成前に取得し、実走中ずっと保持(排他保持中は起動せず待機、取得まで80秒)。
- 私設クローン: `/tmp/aql-portal-return-run-*`。元のLab・設定・ワールド・ユーザーの表示は未接触(jar・設定のハッシュ一致、Labワールド未変更を確認)。

## フィクスチャ(`build_fixture.py`)
- 分離した vanilla 1.21.1 サーバー(loopback、CPUのみ、1回限り)で作ったスーパーフラットのワールド。ワールドzip: `build/aql-portal-return/Aqualumen-Portal-Return.zip`(sha256 `f247b994…`)、サーバーコンソールの記録は同ディレクトリの `fixture.json`。
- 点火済みポータル(obsidian枠、z=−3、x0..1)、白コンクリートのパネル2枚(z=10)、暖色トーチ(−4,−59,9)とソウルトーチ(6,−59,9)。スポーン(1,−60,3)。サバイバル・ピースフル・コマンド不可、夜(18000)固定。
- 平地の人工ワールドであり、自然地形ではない。

## 操作(`run.py`、プレイ中はコマンド・テレポート・テストModなし)
1. スポーンで F3 → 3視点(広角・暖色・ソウル)を F2 撮影(`A-overworld-before-*`)。
2. 歩いてポータルに入る → 5.6秒でネザー(F3 の dimension 行が `the_nether`)。
3. ネザーでF3、約2ブロック歩いて出てF2(`N-nether-outside`)、戻って入る → 4.4秒でオーバーワールド。
4. 戻った位置から歩いて撮影位置へ戻り、同じ3視点をF2撮影(`B-overworld-after-*`)。
- 位置・向き・次元は F3 画面から読んだ値で、ゲーム内部の値ではない。F3画像は `run2/f3-*.png`。

## 確認できたこと
- [比較画像](comparison.jpg)(左が前、右が後。カメラは南向きなので東のソウルトーチが左)。色の数値は [`color-compare.json`](color-compare.json)(各画像の左右半分の最も明るい2%の平均RGB)。前後でR/B比はほぼ同じ(ソウル側 約0.36〜0.38、暖色側 約2.05〜2.19)。
- 保存ワールド: トーチ・壁・ポータルの8つの主要セルは前後で同一。変化は草ブロック→土の8セルで、置いたブロックの下で起きるバニラの変化。ネザー側には `nether_portal` が生成されている。クリーン終了、ログエラーなし。
- Irisのログでは、次元切替のたびにパイプラインが破棄・再作成されている(overworld→nether→overworld)。

## 限界
- 入力は xdotool による自動操作で、人の手動操作ではない。F2は実際のゲーム内スクリーンショット(`*-F2.png`)。
- 前後の画像は炎の動きで画素単位では一致しない。ポータルを使わない対照実行はしていない。
- 光の状態がどこまで引き継がれたかは、このテストでは画像で見える範囲しか示せない。
- 1.8.0のみで、1.9系は未試験。他の時刻・自然地形・複数回往復も未試験。
- 先行の [`run1`](run1/) は帰還後の歩行許容値(0.2ブロック)が厳しすぎ、開始位置の手前0.23ブロックで失敗した(往復自体は成功、証拠は保存)。許容値を0.3にして `run2` を再実行した。

## 再実行
`build_fixture.py`(ワールド生成)→ `/tmp/aqualumen-ground-metrics-venv/bin/python3 -I run.py <名前> --lock-wait 600`。`run.py` は `reports/2026-11-21-lava-light/cavern/run.py` の手順を流用している(元ファイルは未変更)。起動準備に約3.5分かかる。
