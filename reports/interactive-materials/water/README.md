# 洞窟の天井に返る水面光

800×500、24 fps、10秒のCPU試作。水面から反射した太陽光だけを高さ2.8ブロックの平らな天井に加える。Minecraftとシェーダーの動作速度を測ったものではない。

- 0–1.6秒　天窓からの日光が、ゆるいうねりのある水面を照らす。
- 1.6秒と2.5秒　位置の異なる二つの放射状の波束を加える。法線の向きが変わると天井に到達する光が集散する。
- 6.5–8.25秒　天窓を閉じる。水面からの直射反射光はゼロになり、固定の環境光が残る。

直達太陽光の向き、水面での入射角、Schlickのフレネル反射率による重み、天井までの交点を求め、エネルギーを受光テクセルへ双線形に分配する。各光線について、水面から光源方向に戻った交点が天窓に入るかを検査する。天井の穴から空へ戻る反射光は捨てる。天井だけが反射光の受け先で、側壁に先に当たる光は対象外。時間による模様の明滅を描き足す処理は使っていない。

波は解析式で与えた高さ場。プレイヤー接触・波の流体計算、色の多重散乱、任意の地形の一般的な交差判定、GPU上の実装は含まれない。天井の見た目は説明用の岩材・露出・仮想カメラで、ゲームから取り込んだ素材やシェーダー映像ではない。

Python 3 + NumPy + Pillow、ffmpeg、Noto Sans CJKを用意し、`python3 reflect.py`で再生成する。
