# Aqualumen — 水面から天井に返る日光

Minecraft 1.21.1 / Iris 1.8.8用のオプトイン試作。Aqualumen 1.9.0-preview.10と同じクライアント環境を使用。配布パックは `Aqualumen-1.9.0-water-ceiling.zip`。通常のプレビューZIPと独立して選択できる。

## 光の経路

* 透明シャドーパスで、四隅の高さが静水面（8/9ブロック）の値と一致する水ブロックの上面を記録。
* 近傍16×16×16セルを対象に、各水面で16×16点の波と接触波紋の法線を評価。太陽の影マップとボクセル遮蔽で水への日射を確認し、非偏光フレネル反射率を使って空気側へ反射する光束を求める。
* 反射方向の最初の交差を同じ遮蔽場で追跡し、10ブロック以内にあるフルブロックの下面へ、受光面積あたりの光束を8×8点に記録。
* 地形の下面を描く際に材質の反射色を掛けて返す。届いた光はフレームごとに再計算。日の当たらない水面・閉じた屋根・水のない範囲に光源を仮定しない。

## ソフトウェアOpenGL検証

`compile.log` に全プログラムのリンク完了を記録。`probe.cpp` は既知のシャドー深度・屋根・室内カメラ・波紋テクスチャを用意。56枚の平坦な水面頂点を実際の shadow_water.vsh に渡し、全セルで四隅が記録されたことを確認してから、**出荷する shadowcomp5.csh そのもの**をMesa llvmpipeで実行する。出力の固定小数点合計は天窓あり7,146,249、屋根で閉鎖0、水なし0、夜0、天窓あり＋接触波紋7,310,935。接触波紋で2,867受光テクセルが変化した。これはゲームのフレーム時間や照度の物理単位ではない。`Aqualumen-Water-Ceiling-Debug.zip` は地形の天井反射成分を4倍で表示する検証用。

## 適用範囲

平坦な露出水源と水平な石等の下面を対象にし、視点から5.5～7.5ブロックで効果が減衰する。斜面、流れる水、上下に別の水面を挟む経路、壁面の受光、動物による遮蔽、色ガラスの色別反射、雨滴の細かい法線は今回の対象外。上面の高さは元の水面高さ8/9に平均波高を足した値で近似する。日射の透過色は受光点近傍で評価。空気中の散乱やコースティクスの多重反射は計算しない。天窓の真下で太陽が天頂なら、平らな水の反射は窓に戻り、すぐ隣の天井に強い光が出るとは限らない。

私有コピーの `working/` に全ソースを収録。元のシェーダーと通常インスタンスには変更しない。
