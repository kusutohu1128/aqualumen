# Aqualumen 1.0.0 実機検証

2026年11月20日、Minecraft Java 1.21.1 / Iris 1.8.8 / Sodium 0.6.9 と RTX 3080 Ti で通常プレイ版を確認した。Prism Launcher の **Aqualumen Lab** にはシェーダー 1.0.0 と接触波紋用 Mod 0.2.0 を導入した。通常設定でワールドに入り、描画パイプラインと接触Modの初期化、保存終了を確認した。引き渡し時は計測機能を無効にしたタイトル画面。設定は従来の1600×900・上限120 FPSで、1440pの性能値は別の計測起動で取得した。[シェーダーZIP](../../dist/Aqualumen-1.0.0.zip) · [波紋Mod](../../dist/aqualumen-physics-0.2.0.jar) · [通常起動記録](normal-smoke.json) · [引き渡し時の状態](handoff.json)

## 実際の見え方

- **浅い海と川**。以前は岸の砂まで強い青緑に染まっていた。1.0では、浅い場所では砂と砂利の色が残り、岸から離れるにつれて水色と空の反射が強くなる。同じ海岸・視点の手前の領域で、表示RGBの中央値は (86,192,174) から (176,209,166) に変化した。波の位相は撮影ごとに異なり、この値はゲームの画像内の比較に限る。[水辺の新旧比較](comparison.jpg) · [集計領域と数値](water-colour.json)
- **水中からの空**。水深3.25 mの沖と1.10 mの岸際で視点を動かした。以前のスクリーンショットにあった、元画面の四角い輪郭と二重の空は、今回確認した画像では見られない。沖では波に沿って丸い空の縁が揺れる。岸では全反射した砂の段差が水面の裏に見える。縁の雲が筋状に伸びることや、浅瀬で反射の境が強くなることはある。[実ゲーム動画・30秒](water-and-sun.mp4) · [各場面から4枚の抜粋](motion-frames.jpg)
- **太陽と陸上の影**。昼の太陽は中心の円盤を保ったまま、周辺に前方散乱の光が広がる。夕方の比較では、柵と石の階段の足元から草地に影が伸びる。空の明るさが手前のブロックを突き抜けて見えた問題は、実シェーダーを使った遮蔽テストでも確認した。[太陽・水面・夕方の影の新旧比較](sun-and-shadow.jpg) · [遮蔽テスト](native-final.log)

動画は順に沖の水中、岸際の水中、夕方の地上。各10秒、960×540のゲームのフレームバッファーから25 Hzで取得し、750枚をH.264にした。二つの水中シーンではカメラの実際の水没状態も照合した。地上ではゲーム時刻が10600から10799 tickに進む。性能計測は録画を止めて行った。[撮影記録](motion-capture.json) · [実際のカメラとワールド条件](final-motion/capture/)

## 実装と検証範囲

水面はスネルの法則による屈折、Fresnel反射、全反射を使う。水底までの光路長でRGBの吸収と散乱量を決める。画面から見えにくい砂底は、影の描画時に記録した材質と位置から光線が通るブロックを順に調べる。水中の垂直面では、近くの水底で一度反射した日光も近似する。ボート接触時は局所的な高さ場の計算に力を加える。水量や流路の変化はMinecraft側の挙動に従う。[通常版ソース](../../release/shaders/) · [ボートの接触記録](final-play/capture/boat-contact.json)

1. 岸の実ワールドから得た16本の屈折光線について、最初に交差する砂ブロックの面と距離を保存地形から独立に算出した。初期の候補は手前の砂を飛び越す場合があった。修正後は過去に画面から見えていなかった8本を含め16本すべてで面の向きと距離が一致し、距離の最大誤差は0.00000164 m未満だった。これは正午付近の対象地点・光線での結果。[光線ごとの照合記録](shore-proof/geometry.json) · [照合コード](verify_geometry.py)
2. 陸上の影は実際の影描画コードを使い、遮蔽物の有無、足元の小さい隙間、切り抜き、斜面・影マップ端などの26条件をNVIDIA GPU上で検査した。全条件が判定を通過した。不透明な手前の面は、16・64・128 mの各試験で背後に雲を置いても出力差がゼロで、約8.25 mの影内でも前方散乱の追加による差はゼロだった。[影26条件](final-land-native/RESULT.json) · [通常版GPU検査](native-final.log)
3. Claude Opusを設計相談と候補版の新旧静止画レビューに使用した。浅瀬の色、海草の二重像、画面の矩形を独立に見てもらい、縁の筋やブロック側面の形が目立つ点も記録した。最終版の距離照合・動画・フレーム時間・通常起動はその後に取得した。[設計助言](advisor.json) · [候補版の目視所見](visual-advisor.json)

カメラと影の両方から見えない地形、植物、遠距離の反射には近似が残る。砂の段差には三角形状の暗い側面が見え、水中の映像には小さな暗い点が残る。点の由来は未特定。太陽の見かけの直径は約0.53度とし、その周囲の空を二つの指向性散乱成分で近似した。実測の海水や特定の天候への分光校正は行っていない。タイトル起動時、NVIDIAコンパイラーが `bed.travel` の初期化について警告した。コードでは交差成功時に距離を書き込み、成功フラグを確認してから読む。実機ではパイプラインを生成し、17場面でシェーダーが有効だった。
