# 木陰と設置光源の実ゲーム比較

Aqualumen 1.2.1では、松明を木の下に置くと、炎を向いた幹と草に暖色が届きます。木が遮る太陽と、横から照らす松明には、それぞれ別の光路を使います。光源を消す、石を間に置く、赤いガラスに替える、魂の松明を足すという操作を実際のMinecraftで比較しました。[通常プレイ用ZIP](../../dist/Aqualumen-1.2.1.zip) · [木陰の比較](canopy-final.jpg) · [自然生成のシラカバ](forest-final.jpg) · [室内の6条件](placed-lights-final.jpg)

## 森、室内、水辺で見える違い

| 場面 | 比較方法 |
| --- | --- |
| 木陰 | 同じ時刻・同じ視点で、木の下の松明を外した場合と置いた場合を撮影。幹・手前の草・日なたの草を、実際の描画行列から投影した9×9画素で測定。[数値](measurements.json) |
| 自然の森 | シラカバの根元から2.24ブロック離れた草の上に松明を設置。午後と夜間のそれぞれで消灯・松明・魂の松明を比較。既存の木、葉、地面を使い、松明の位置だけを切り替えた。[実画像](forest-final.jpg) |
| 室内 | 暖色のみ、寒色のみ、同時点灯、仕切りの有無、石と赤いガラスを比較。ガラスを通らずカメラから直接見える奥の壁でも受光色が変わる。[実画像](placed-lights-final.jpg) |
| 夜の水辺 | 水際のランタンを消して点灯。揺れる表面に映る室内の明かりに、光源そのものの鏡面反射が重なる。[実画像](water-final.jpg) · [反射成分を取り出した実ゲーム出力](optics/capture/lamp-night-water.png) |
| 歩行 | 夜の点灯した部屋を見ながら5ブロック横移動。記録した目線と描画行列から同じ壁の点を追跡し、8ブロックごとに更新する光源格子の境界を通過した瞬間を測定。[10秒の動画](final-walk.mp4) · [追跡値](final-walk-measurements.json) |

午後・夜の森林撮影ではゲーム時刻とカメラを固定しています。草木、波、雲のアニメーションには時間差があります。室内の反射計測用の別撮りでは、波と雲の時刻も固定しました。

## 光の計算と範囲

Irisが影の描画に渡すブロック座標と発光量を読み、周囲64×64×64ブロックに光源・遮蔽物を記録します。各面に対し、光源までの距離、面の向き、石や葉を通過する区間を求めます。色ガラスは通過した厚さに応じて各色を減衰させます。標準設定では有限サイズの光源上の3点を調べます。水面には波の法線と光源・カメラの方向からGGX鏡面反射を加えます。[光源と遮蔽の実装](../../release/shaders/lib/local_lighting.glsl) · [点光源と距離減衰](https://www.pbr-book.org/4ed/Light_Sources/Point_Lights) · [Irisの発光属性](https://shaders.properties/current/reference/attributes/at_midblock/)

範囲は1灯につき14ブロック、8×8×8ブロックの区画に最大12灯です。視点を中心とする立方体の各軸19〜24ブロックで詳細な照明からMinecraftのブロック光に移行します。間接光は伝播したブロック光から推定します。葉の密度、ガラスの透過色、スラブ・柵の形状は近似です。柵は中央の柱で遮蔽を求めます。色ガラスの対応はフルブロックです。手持ちの灯火、動く生物による設置光の遮蔽、色の付いた壁からの二次反射が次の課題です。[長期目標と実ゲームでの判定条件](../../docs/REALISM_GOAL.md)

夜に強く照らされた室内では、画面中央を重く評価したHDR輝度から露出を下げます。明るい場所に向くと約0.45秒、暗い場所に戻ると約1.8秒の時定数で順応します。炎のごく近くのにじみは、実際に見えている発光画素から計算します。Irisの光の設定で露出順応とにじみの強さを個別に調整できます。[前版との比較](exposure.jpg) · [露出の実装](../../release/shaders/composite3.csh) · [光源のにじみの参考文献](https://www.graphics.cornell.edu/pubs/1995/SSZG95.pdf)

## 太陽と松明を区別した測定

診断版では、直射太陽光を赤、水面に直接映るランタンを緑に出力しました。木陰の幹と手前の草は点灯前後とも太陽の値が0、日なたの草はどちらも222.62でした。数値は0〜255の診断用符号化後の9×9画素平均です。夜の水面で反射成分が出た画素は消灯で0、ランタン点灯で2,870、うち324画素が128を超えました。鏡面方向付近は平均228.90でした。診断版は1.2.0から作り、1.2.1と光源・地形照明・水面の該当ソースがバイト単位で一致することを確認しています。[診断記録](optics-evidence.json) · [点灯前後の測定点](measurements.json)

## Claudeとの共同作業と外部比較

Claudeは試験用の部屋・森林の条件作成、GPUの回帰検査、実画像のレビューに参加しました。Opusから夜の白壁の明るさで炎が埋もれるという指摘を受け、1.2.1では夜の露出順応と発光部だけのにじみを実装しました。GPU試験では、通常の白い壁からにじみが生じないこと、隠れた光源から画面に光がにじまないこと、奇数幅でもフィルタの総量が保存されることを確認しました。[最初の画像レビュー](final-visual-advisor.json) · [GPU試験結果](gl-1.2.1-final.log)

1.2.1の画像を見たOpusも、木陰で幹の下半分だけが暖かくなること、石壁の奥に暗さが残ることを確認しました。夜の白樺では光の届く範囲が広く、魂の松明だけの白い部屋では青みが一様に見えるという所見が残っています。距離減衰は計算と実測に表れていますが、炎の色・明るい面の階調にはさらに調整の余地があります。[配布版の画像レビュー原文](final-1.2.1-visual.json)

以前のAqualumen 1.1.0およびPhoton v1.1の標準設定でも同じ部屋を撮影しました。画像では壁の光の広がりと、通常の松明・魂の松明の色を見比べられます。森林の構図と物理モデルはAqualumen独自のものです。[同じ部屋での3パック比較](reference-final.jpg) · [Photonの公開設定](https://github.com/sixthsurge/photon/blob/main/shaders/shaders.properties)

## 通常のLabへの導入

選択中のシェーダーは `Aqualumen-1.2.1.zip`、接触波紋Modは `0.2.0` です。配布ZIPのSHA-256は `10ba98a77bec5901e2a5e6be81b557b9419fdd3b48b2229843be41dd97393a06` で、ソースからの再ビルドと導入先のZIPが一致しました。元のLabの計測Mod・有効化マーカーを外した状態で検証ワールドの描画と保存を確認し、通常起動のタイトル画面で引き渡しました。通常セーブ41ファイルと通常Modの内容、ゲーム設定の各値を照合しています。[通常起動の記録](normal-smoke.json) · [引き渡し状態](handoff.json) · [タイトル画面](lab-title.jpg)

試験はUUIDを確認した使い捨てのワールド複製で実施しました。各撮影の生データをファイルごとのSHA-256で照合してから、作業用複製14個を片付けました。初期の試験で撮影前に中止した1件も中止記録として保存しています。[複製の照合記録](scratch-cleanup.json) · [森の最終監査](forest-final-postcheck.json)
