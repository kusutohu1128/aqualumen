# 細かい波を反射・屈折へ統合する TEST

2026-10-03 JST。**実装・実ゲームでの動作確認まで進展。見た目は未合格、通常版未採用。最終目標は未達。**

解像できる波と細かい波の分布を分け、9方向の反射・屈折・全反射を
評価する光学処理を実装した。水面形状・屈折率・光の単位は親TESTから
変更せず、通常シェーダーと配布版0.8.6には組み込んでいない。

## 確認したこと

- テスト先行：実描画経路の未実装 RED→実装 GREEN。
- 不正な波の分布を受け入れる不具合を実GPUで再現し、ガードだけ修正。
  同じ境界テストで波ゼロ・全反射・非適用条件を含め全項目合格。
- RTX3080Ti上で描画色・深度・観測表示の非干渉、反復、一定色入力を確認。
- 実ゲームの浅い水中・深い水中・斜め視点を、変更前後6画面で記録。
  後続の選択点48点で新処理の適用を確認。Irisのフォールバックなし。
- 独立した読取り専用監査で6枚の画像・撮影姿勢と3,552フレームのCSVを
  再確認し、後続48点の数値条件を別途再計算。
- CPU23テスト合格。最初の実読出しで判明した未使用C13–15の形式違いも、
  失敗記録を残して最小修正。生データや数値基準は変更していない。

これは限定条件での動作確認であり、エネルギー保存・相反性・全視点の
物理的正しさ・動き・最低FPSの保証ではない。係数の反射＋透過=1と
光量の物理的な保存は区別している。

## 採用しない理由と次の検証

TESTでは太陽が複数の小さな明点に分かれ、水面の縁の筋・折れ返りも残る。
9方向の離散評価による光のサンプリング不足が有力だが、原因の切り分けは
まだ終わっていない。次は光源の角度積分と全反射境界を別々に検証する。
暗い外周・画面外の反射・岸辺・夜雨・動作中の安定性も引き続き対象。

左上だけが最終色で、ほかは診断表示。緑・紫・黄色を通常のゲーム画面の
欠損テクスチャと解釈しないこと。画像と後続のGPU読出しは同じフレームではない。
