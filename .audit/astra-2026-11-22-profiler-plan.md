# In-game GPU pass timings for Aqualumen — plan for Devin, HEAD `98725a3`

Measure how much of a rendered frame goes to shadow capture, lighting-field updates, visible terrain and fullscreen shading. Compare the same scenes across packs, then change one lamp at a fixed camera. The existing FPS comparisons motivate these tests. Register pressure, occupancy and the cost of an individual shadow ray remain hypotheses.

## Query lifecycle and isolation

- Use `GL_TIMESTAMP` via `glQueryCounter` on the game's current render context. Check OpenGL 3.3 **or** ARB_timer_query and nonzero timestamp counter bits at runtime (the historical game reports GL 3.2). Preallocate 16 frame slots × 256 timestamp names outside the measured window. Reserve room for frame end, use a small stack for nested ranges and reuse a boundary where possible. [Khronos timer query](https://registry.khronos.org/OpenGL/extensions/ARB/ARB_timer_query.txt)
- At frame start inspect slots at least eight frames old. Poll `GL_QUERY_RESULT_AVAILABLE` on the closing timestamp; read 64-bit results only when available in command order. Defer busy slots; when the ring, marker budget or bounded writer queue fills, mark a dropped frame and keep rendering. Never reuse an outstanding ID, wait, spin, flush, finish, insert a fence wait or perform synchronous GPU readback. Reject invalid ordering and ambiguous counter wrap. Discard unfinished frames on exceptions/context changes.
- Timestamp calls require no program, FBO, texture, VAO, viewport, query-target binding, or debug-group changes. On contexts supporting query buffers, defer client-memory reads while a query buffer is bound. Leave existing queries alone. Delete owned queries only on their owning current context, clear identity maps on pipeline teardown and separate epochs on reload. Use a private smoke-only before/after state check with pre-existing GL state; disable it for timings.
- Let `R = reports/2026-11-22-gpu-profile` and `T = reports/2026-11-21-animal-light`. New `R/run.py` reuses `T/run.py`'s guarded VirtualGL runner, scene and frame observer, directs output to `R/runs/<label>/`, and copies the profiler only for `--gpu-profile on`. Private game must resolve to `/tmp/aql-v190-run-*/minecraft`. Require a new opt-in marker bound to canonical game path, run ID and pack SHA plus the integrated, non-public server's exact `saves/AqualumenNaturalV2` and `world_id=b22dbccb-2970-41e6-847f-f183b1ec923d`. Verify seed 308060 at clone time. Revalidate on server/world changes. Pre-world shader metadata can be cached in opted-in memory; gate all query allocation, timing and file output on full authorization.
- Store the mod's raw stream inside the private game. Extend the existing runner with an optional collection callback before successful clone cleanup. Flush completed rows during play; it sends SIGTERM at the end, so never rely on a shutdown hook. Require a flushed watermark past the selected window before ending collection, with a bounded timeout. Restrict output and collection to the runner-created paths. Keep the Lab 1.8 selection, active physics 0.2, disabled compiler, optional packs and original world/config hashes verified against preflight. No Lab installation.

- In each frame sum repeated invocations of the same range, compute exclusive time by subtracting the union of its direct children, and retain inclusive parents for inspection. For every accepted frame check children lie inside parents, siblings do not overlap and exclusive + independently computed gaps reconcile to whole within 0.02 ms.
