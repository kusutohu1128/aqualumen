## Acceptance boundaries for the new method

- Instrumentation must add only observation stores/MRT outputs, preserve every production return value, branch, texture operation, derivative location, vertex program and framebuffer depth test, and compare instrumented colour/depth against the uninstrumented program at the exact endpoints. Float equality/tolerance and repeat error must be reported; a compiled instrumented program alone does not establish non-interference.
- A independent closed-box raycast must select the **first boundary of the union** from the recorded GPU origin/direction. Nearest positive entry works only for an outside origin; an inside origin requires a valid exit or explicit rejection. Partition IDs/axis IDs are not automatically physical edges: coplanar neighboring boxes can be one continuous receiver. Ties and tangent/edge contacts need explicit tolerances and an unresolved label.
- Keep separate: (1) exact continuous physical ray/receiver; (2) that receiver's visibility to the camera and projection; (3) the production sampled screen-depth receiver and its footprint; (4) the solver's accepted receiver/confidence or miss. A physical hit hidden behind another camera-visible face is not available to the screen-space algorithm. A camera-visible sampled face is not necessarily on the transmitted ray.
- NEAREST face/texel boundaries and LINEAR mixtures across silhouettes are lawful input-selection changes unless independently qualified otherwise. LINEAR reconstructed depth is not a ground-truth solid surface. Retain both filters separately and inspect source footprints at both endpoints and refinement midpoints, not just original-UV quads.
- Use the same fixed baseline pixel and high-precision b endpoints; record full quad observations because normal/roughness derivatives couple neighbors. Eight halvings show scale behavior, not an asymptotic continuity proof. A real receiver, material, visibility or wet/dry edge must not be relabeled as a solver defect, and no bank guard should be weakened to obtain GREEN.
